# 章节创作器

> 用于单章节内容创作，支持续写和优化两种模式

---

## 模板A：续写模式

```
请续写{章节序号}章，章节名：{章节名}

【前情提要】
{上一章结尾3-5句话摘要}

【本章目标】
- 核心事件：{本章要发生什么}
- 爽点/冲突：{本章的情绪点}
- 字数目标：{800-2000字}

【本章设定】
- 出场人物：{人物列表}
- 场景地点：{地点}
- 时间：{时间点}

【风格要求】
- 叙事节奏：{快节奏/慢节奏/交替}
- 情感基调：{热血/温馨/压抑/悬疑}
- 视角：{第三人称/第一人称}

【创作要求】
1. 直接输出正文，无需开头结尾解释
2. 段落控制在3-5句，避免超长段落
3. 对话占比30-40%，穿插动作和场景描写
4. 结尾留钩子，引导读者继续阅读
5. 融入本章设定的所有要素
```

---

## 模板B：优化模式

```
请优化以下章节内容：

【原文】
{粘贴原文}

【优化目标】
- 问题诊断：{指出具体问题，如节奏拖沓/对话生硬/描写不足}
- 优化方向：{改进建议}
- 保持要素：{必须保留的内容}

【风格要求】
- 参考作者：{如有}
- 字数范围：{保持/增加/减少}
```

---

## 适用场景

### 续写模式
- ✅ 日常章节创作
- ✅ 卡文时续写
- ✅ 批量生成章节

### 优化模式
- ✅ 初稿润色
- ✅ 节奏调整
- ✅ 问题修复

## 变量说明

| 变量 | 示例 | 必填 |
|------|------|------|
| 章节序号 | 第1章/第15章/第128章 | ✅ |
| 章节名 | 初入宗门/觉醒之时/逆袭 | ✅ |
| 前情提要 | 上一章关键事件摘要 | ✅ |
| 核心事件 | 主角突破境界/遭遇埋伏 | ✅ |
| 爽点/冲突 | 打脸/收获/危机 | ✅ |
| 字数目标 | 1500-2000 | ❌ |
| 出场人物 | 主角+配角列表 | ❌ |
| 场景地点 | 修炼室/集市/擂台 | ❌ |
| 叙事节奏 | 快节奏/慢节奏 | ❌ |
| 情感基调 | 热血/压抑/温馨 | ❌ |

---

## 章节创作原则

1. **开篇钩子**：每章开头要有吸引力
2. **节奏控制**：避免连续3段无推进
3. **对话占比**：30-40%，不宜过多过少
4. **段落长度**：3-5句为最佳，不超过7句
5. **结尾留钩**：每章结尾要有悬念或期待
