# 大纲生成器

> 用于小说整体大纲创作，适用于长篇网文

---

## 模板

```
请为我创作一个{小说类型}小说的大纲，设定如下：

【基础信息】
- 小说类型：{小说类型}
- 目标平台：{发布平台}（起点/番茄/晋江/七猫）
- 预计字数：{预计总字数}万字
- 预计章节：{预计章节数}章

【核心设定】
- 主角姓名：{主角姓名}
- 主角性格：{主角性格关键词}
- 金手指设定：{核心优势}

【世界设定】
- 时代背景：{历史/现代/未来}
- 世界等级：{力量体系/社会等级}
- 主要势力：{势力分布}

【创作要求】
1. 完整的三幕式结构（起承转合）
2. 至少30章的详细章节大纲
3. 每章需包含：章节名、核心事件、爽点/钩子、字数预估
4. 主角成长路线清晰（从弱到强的关键节点）
5. 至少3条主线（成长线/感情线/事业线）
6. 主要反派和关键配角设定
7. 高潮节奏规划（每10章一个小高潮，每50章一个大高潮）

【输出格式】
- 使用Markdown表格展示章节大纲
- 重要节点用 ⭐ 标注
- 关键伏笔用 🔮 标注
```

---

## 适用场景

- ✅ 长篇连载小说（30万字以上）
- ✅ 需要IP改编潜力的作品
- ✅ 多主角/多视角叙事

---

## 变量说明

| 变量 | 示例 | 必填 |
|------|------|------|
| 小说类型 | 玄幻/都市/科幻/历史/言情 | ✅ |
| 发布平台 | 起点/番茄/晋江/七猫 | ✅ |
| 预计总字数 | 50/100/200 | ✅ |
| 预计章节数 | 200/500/1000 | ✅ |
| 主角姓名 | 林动/叶凡/萧炎 | ✅ |
| 主角性格 | 隐忍/腹黑/热血 | ✅ |
| 核心优势 | 签到系统/重生先知/神秘血脉 | ✅ |
| 历史/现代/未来 | 古代/现代/2077年 | ✅ |
| 力量体系 | 炼气/筑基/金丹... | ❌ |
| 势力分布 | 宗门/家族/帝国 | ❌ |

## 参考案例

### 案例1：玄幻修真
- 类型：玄幻
- 平台：起点
- 字数：200万
- 类型：炼气→筑基→金丹→元婴→化神
- 优势：神秘玉佩中的空间
- 势力：三大圣地、十大宗门

### 案例2：都市异能
- 类型：都市
- 平台：番茄
- 字数：100万
- 类型：现代都市
- 优势：能看见他人命格
- 势力：异能者联盟、财阀世家

### 案例3：科幻星际
- 类型：科幻
- 平台：起点
- 字数：150万
- 类型：星际时代
- 优势：掌握失落科技
- 势力：星际联邦、异族联盟
