## 决策树

### 面对冲突时

```
冲突类型 → 首选策略
├─ 林玄被欺负 → 直接出面制止（不绕弯子）
├─ 自己受委屈 → 冷静分析，找机会反击（不哭不闹）
├─ 面对强者 → 暂避锋芒，寻找其他途径（不硬拼）
├─ 涉及林玄安全 → 不惜一切代价（打破一贯冷静）
└─ 涉及家族名誉 → 理性权衡，不做冲动决定
```

### 面对选择时

```
选择类型 → 决策逻辑
├─ 个人安全 vs 林玄安全 → 林玄优先（这是她唯一的底线）
├─ 宗门规矩 vs 正义 → 正义优先（她本就因异色瞳被规矩排挤）
├─ 感情表达 vs 沉默 → 沉默（不擅长直说，用行动代替）
└─ 家族利益 vs 林玄 → 陷入两难（核心内心冲突）
```

## 台词指纹

### 语言特征

| 特征 | 表现 |
|------|------|
| 句长 | 中等，平均10-15字/句 |
| 语气词 | 偶尔用「罢了」「随便你」 |
| 口头禅 | 无固定口头禅，但常用省略号表示未尽之言 |
| 回应方式 | 冷淡中带关心，语气平静但眼神会出卖情绪 |
| 情绪泄露 | 害羞或担心时会刻意提高音量或转移话题 |

### 典型句式

```
✅ 符合苏婉的说话方式：
- "……随便你。"
- "你自己知道该怎么做。"
- "别死在半道上。"
- "我说了，你没必要……"（被打断）
- "你的剑，比他们的干净。"
- "……嗯。"（唯一认同时的简短回应）

❌ 不符合苏婉的说话方式：
- "我觉得我们也许可以一起想办法！"（过于热情）
- "你放心，我一定会帮你的！"（过于直白）
- "你为什么总是不说话？"（她不会主动追问太多）
- "我好担心你啊！"（不会直接说担心）
- "我们一起来对抗命运吧！"（不说口号）
```

### 情绪表达时的语言

| 情绪 | 表达方式 | 示例 |
|------|---------|------|
| 关心 | 冷淡包裹 | "你又在拼命了。"（实际是担心） |
| 害羞 | 转移话题 | "别误会，我只是多炼了一份。" |
| 愤怒 | 冰冷刺骨 | "你动他一下试试。"（语速慢，每个字清晰） |
| 担心 | 假装不在意 | "死在外面别让我收尸。" |
| 感动 | 沉默+小动作 | 低头摆弄药瓶，不说话 |

## 行动模式

### 战斗风格

| 阶段 | 行为 | 说明 |
|------|------|------|
| 前期 | 远程消耗+辅助 | 冰系剑法保持距离，同时准备丹药 |
| 中期 | 冰魄剑诀觉醒 | 冰灵体完全发挥，冻结对手行动 |
| 后期 | 与林玄配合 | 林玄近身，她远程控制，形成配合 |

### 日常行为

```
修炼：白天练剑，晚上炼丹（经常熬夜）
社交：独来独往，不参加群体活动，但会在远处观察林玄
饮食：清淡，炼丹用的药材会掺进日常饮食
睡眠：少，经常在炼丹房里睡
习惯：紧张或思考时会摸腰间的淡青色小药瓶
```

## 人际化学反应

### 对不同角色的态度

| 角色 | 态度 | 互动模式 |
|------|------|---------|
| 林玄 | 暗恋+守护+心疼 | 默默准备丹药，在他受伤时「恰好」经过；不敢直视他的眼睛 |
| 赵霸 | 敌视+警惕 | 多次当面制止他欺负林玄；被他记恨但不畏惧 |
| 赵无咎 | 防备+调查 | 察觉他对林玄的关注不对劲，开始暗中查赵家 |
| 外门弟子 | 疏离 | 不主动社交，但不逃避必要的交流 |
| 苏家 | 责任+压力 | 作为家主之女，需要维护家族名誉，但这与她保护林玄的愿望冲突 |

### 冲突处理方式

```
被挑衅 → 冷静回击，不情绪化（但与赵霸不同，她不羞辱对方）
被误解 → 不解释，等对方自己发现
被帮助 → 记在心里，找机会回报
被击败 → 分析原因，下次改进，不沉溺于挫败感
```

## 情感表达

### 情绪曲线

```
日常：冷淡（60%）→ 观察（30%）→ 担忧（10%，主要关于林玄）
战斗：冷静（70%）→ 专注（20%）→ 紧张（10%，担心林玄受伤）
危机：果断（50%）→ 坚决（30%）→ 脆弱（20%，仅在林玄面前会流露）
```

### 情感触发点

| 触发情境 | 情感反应 | 外部表现 |
|---------|---------|---------|
| 林玄受伤 | 心疼+自责（觉得自己没保护好他） | 手微微发抖，但强装镇定 |
| 林玄说谢谢 | 慌乱+害羞 | 别过脸，说「随便你」 |
| 被人说女子不如男 | 愤怒+坚定 | 眼神变冷，用实力回应 |
| 发现冰灵体和混沌体有关联 | 好奇+不安 | 开始认真研究两种体质的资料 |
| 林玄差点死掉 | 恐惧+爆发 | 第一次不顾一切冲上去，打破一贯冷静 |

## 成长弧光

### 第1-5章：守护期
- 状态：默默关注，偷偷帮助
- 行为：送丹药，劝阻，旁观
- 心态：喜欢他，但不敢说；觉得自己的冰灵体可能和他有关
- 关键事件：第1章送培元丹，第2章劝阻赵霸，第3章见证混沌体觉醒

### 第6-15章：介入期
- 状态：从默默守护到主动介入
- 行为：开始直接与赵霸对峙；调查冰灵体与混沌体的联系
- 心态：不能再只是旁观，必须做点什么
- 关键事件：发现冰灵体可以缓和混沌体的反噬；与林玄关系升温

### 第16-30章：并肩期
- 状态：与林玄并肩作战
- 行为：共同面对赵无咎和血海宫；感情明朗化
- 心态：接受自己的感情，不再隐藏
- 关键事件：赵无咎暴露与血海宫的联系；冰灵体+混沌体的协同效应被发现

## 创作检查清单

写苏婉时，检查以下项目：

- [ ] 对话是否冷淡但有内容（不啰嗦也不空洞）？
- [ ] 是否避免了过于直白的感情表达（用行动和省略号代替）？
- [ ] 在林玄面前是否比在其他角色面前稍微柔和一点？
- [ ] 是否在担心的时候用「别死在半道上」这种方式表达？
- [ ] 是否体现了「外冷内热」的反差（表面冷淡，实际极度在意）？
- [ ] 面对赵霸时是否展现了不同于对其他人的强硬？
- [ ] 是否在涉及冰灵体和混沌体关系时表现出研究者的好奇心？
