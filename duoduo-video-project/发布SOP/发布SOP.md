# 发布 SOP

> 每天半小时，流水线操作。

---

## 每日发布流程

### 上午（30分钟）
1. **选品**（5分钟）— 在选品广场挑3-5个高佣金商品
2. **找素材**（10分钟）— 抖音/快手搜相关品类热门视频，下载3-5条
3. **去重剪辑**（10分钟）— 剪映套用去重手法 + 加字幕
4. **发布挂链**（5分钟）— 发布视频，挂上对应商品链接

### 下午/晚上（15分钟）
5. **补发**（15分钟）— 再发3-5条，总量保持每天10条以上

## 发布节奏

- **日更量：** 10-30条/号
- **发布时间：** 午间12:00-13:00、晚20:00-22:00（流量高峰）
- **多号策略：** 初期2-3个号同步运营

## 账号管理

| 维度 | 要求 |
|------|------|
| 实名认证 | 必须的，一个身份证可开多个号 |
| 养号期 | 新号先正常刷视频3-5天再发带货 |
| 垂直度 | 一个号专注1-2个品类 |
| 违规 | 不搬运有版权争议的内容，不夸大宣传 |

## 数据复盘（每周）

- 哪条视频爆了？为什么？
- 哪个品类转化好？
- 哪个时段发布效果好？
- 下周调整方向？
