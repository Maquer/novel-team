## 六、去重 SOP（剪映操作步骤）

### 通用步骤（所有品类必做）

| 步骤 | 操作 | 参数 |
|------|------|------|
| ① 导入素材 | 剪映 → 新建项目 → 导入视频 | — |
| ② 掐头去尾 | 删除开头+结尾各 0.5-1秒（黑场/无关部分） | — |
| ③ 变速 | 速度 → **1.05x-1.15x**（1.05x最安全） | 太快影响观感 |
| ④ 镜像翻转 | 编辑 → 镜像（90%视频适用） | 有文字的画面跳过此步 |
| ⑤ 抽帧 | 随机选 2-3 个位置，每处用"分割"删除 1-2帧 | 破坏视频指纹 |
| ⑥ 加滤镜 | 滤镜 → "日系"或"冷白" → **强度 10-20%** | 不要超过30% |
| ⑦ 调参数 | 对比度+3、饱和度+5、锐化+10 | 微调不夸张 |
| ⑧ 换BGM | 音频 → 音乐 → 热门卡点音 → **音量50%** | 替换原声 |
| ⑨ 加贴纸/水印 | 右下角加白色logo/贴纸 → **5%透明度** → 持续1-2秒 | 标记原创痕迹 |
| ⑩ 导出 | 分辨率 **1080p**、帧率 **30fps**、码率"推荐" | — |

### 品类A特化（文具/宿舍）
- **抽帧加密：** 每 5-10 秒抽 1 帧（比通用更频繁）
- **叠加黑白滤镜：** 5% 强度，叠加在通用滤镜之上
- **人声变声：** 有讲解的视频，用"变声"功能选"大叔"或"萝莉"，强度50%

### 品类B特化（降温品）
- **变速更激进：** 1.1x-1.2x（降温品展示动作快）
- **倒放：** 展示过程类视频可尝试倒放（如喷雾喷出），天然去重
- **画面裁剪：** 9:16 裁为 1:1 或 4:3，再填充回 9:16，破坏原构图
