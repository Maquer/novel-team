## 第二步：剪映去重编辑（每条20-30分钟）

### 品类A：文具类（清单图文优先）

**第1条（林夕同学图文）：** 这是图文笔记，用剪映重新制作
1. 剪映 → 新建项目 → 选10-15张文具图片（从原笔记截图或重新找图）
2. 每张停留1.5秒 → 配合节奏卡点音乐
3. 转场：「叠化」或「擦除」，每张之间切换
4. 加字幕：每张图片配一句文字说明（标题+关键词）
5. BGM：搜索「轻松」「治愈」类音乐，音量30%
6. 导出：1080P，帧率30fps

**第2-4条（视频类）通用流程：**
1. 导入素材 → 抽帧加密（间隔15帧抽1帧）
2. 主轨道变速：1.08x-1.12x
3. 画面滤镜：黑白→亮度-30%→对比度+15%
4. 倒放：随机选2-3段0.5-1秒倒放
5. 字幕重建：手动重写，语气口语化
6. BGM：换一首原视频没有的音乐
7. 导出：1080P，帧率30fps

### 品类B：降温类

1. 导入素材 → 画面裁剪：旋转-3°+裁掉4%边缘
2. 画中画：叠加1层模糊遮罩（透明度8%）
3. 变速：分段处理——开头0.8x慢放吸睛→中间1.1x→结尾1.2x
4. 滤镜：降低饱和度（-25%）+ 提高亮度（+15%）
5. 字幕：重写为疑问句式开头（"夏天宿舍没空调？..."）
6. BGM：换一首"清凉""夏风"类音乐
7. 导出：1080P，帧率30fps

> 剪映「智能去重」功能（如有）先用，再用手动方法加固
> ⚠️ 去重不是越复杂越好——画面不自然比轻微重复更糟

## 第三步：拼多多发布（每条15-20分钟）

### 发布步骤

1. 打开拼多多App
2. 底部 →「发现」或「多多视频」
3. 点「+」发布 → 从相册选择编辑好的视频
4. 填写标题 + 描述：
   - 标题模板：「开学必备！XXX神器，学生党快冲🏃‍♂️」
   - 描述模板：「学生党必看！开学好物分享，亲测好用✨」
5. **关键一步——加商品链接：**
   - 找到「添加商品」或「挂商品链接」按钮
   - 从你的选品广场/收藏夹中选对应商品
   - 选好后链接会显示在视频下方
6. 添加话题标签（从下方选3-5个）
7. 检查预览 → 发布
