# 素材来源与去重

> 搬运不是抄袭。去重做到位，就是「二次创作」。

---

## 一、素材来源

| 来源 | 质量 | 风险 | 推荐度 |
|------|------|------|--------|
| 抖音热门带货视频 | 高 | 中（去重难） | ⭐⭐⭐⭐ |
| 快手热门带货视频 | 中 | 中 | ⭐⭐⭐ |
| 拼多多站内视频 | 低 | 低（同质化严重） | ⭐⭐ |
| 自己拍/拍实物 | 高 | 低 | ⭐⭐⭐⭐⭐（但门槛高） |

## 二、去重手法（至少用3种）

| 手法 | 操作 | 效果 |
|------|------|------|
| 改帧率 | 24fps → 25fps 或 30fps → 29.97fps | 基础去重 |
| 镜像翻转 | 左右翻转画面 | 视觉差异 |
| 换BGM | 替换背景音乐 | 听觉差异 |
| 加滤镜 | 剪映加调色滤镜 | 颜色差异 |
| 加字幕 | 手动加文字字幕 | 内容差异 |
| 剪辑重排 | 删减/重新排序片段 | 结构差异 |
| 画中画 | 加边框或画中画效果 | 构图差异 |
| 变速 | 1.05x 或 0.95x 倍速 | 时间差异 |

## 三、搬运 SOP

1. 找到目标视频（抖音/快手热门带货）
2. 用下载工具存到本地（不带水印）
3. 剪映导入 → 套用去重手法（至少3种）
4. 加字幕 → 配文案
5. 导出 → 发布挂链接

## 四、风险注意

- 抖音有跨平台搬运检测，过于雷同的视频可能被限流
- 建议每条视频都原创文案/字幕，降低检测概率
- 长期策略：逐步增加自己拍/自己剪的比例
