# 平台规则研究

> 了解平台规则，避免违规封号。

---

## 一、多多视频带货开通

- **入口：** 拼多多 App → 底部「多多视频」→ 右上角「创作者中心」
- **门槛：** 实名认证即可，零粉丝
- **资质：** 身份证即可，无需营业执照

## 二、内容规则

| 规则 | 说明 |
|------|------|
| 视频时长 | 建议 15-60 秒，过长影响完播率 |
| 画质要求 | 720p 以上，横竖屏均可（竖屏优先） |
| 挂链要求 | 必须挂商品链接才能参与佣金分成 |
| 一视频一链接 | 一条视频只能挂一个商品链接 |
| 多账号 | 同一身份证可开多个号（建议不超过5个） |

## 三、搬运/二创规则

- 拼多多对搬运内容的检测机制不如抖音严格
- 但仍建议：每条视频至少 3 种去重手法
- 过于雷同的视频可能被降权或限流
- **底线：** 必须添加自己的字幕/文案/剪辑处理

## 四、违规红线

| 违规行为 | 后果 |
|---------|------|
| 搬运有版权争议的内容（如电影片段） | 链接下架 |
| 虚假宣传（夸大功效、虚假价格） | 账号降权 |
| 频繁发布同质内容 | 限流 |
| 刷量/刷播放 | 封号 |
| 售卖违禁品 | 封号+冻结佣金 |

## 五、佣金结算规则

- 佣金按月结算，T+7 到账
- 用户退款后，已结算佣金扣除
- 技术服务费：每单扣除约 1-2 元
- 首次提现无门槛

## 六、账号权重机制

- 新号有 7 天观察期（流量池较小）
- 连续发布优质内容可逐步提升权重
- 数据指标：完播率 > 点赞率 > 转化率 > 评论率
- 被限流后需要 3-7 天恢复正常流量
