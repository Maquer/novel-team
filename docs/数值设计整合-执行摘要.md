## 落地的四项改动

### 1. power-model-v4.py — 属性四层金字塔
**ch12 方法论落地。** 之前 v3 把所有加成混乘一层，v4 拆成：
```
稳定层（功法×装备）→ 临时层（心境×实战）→ 跨境界压制系数（独立判断）
```
新增 `--verify` / `--verify-gaps` / `--verify-economy` 自动检查。

### 2. breakthrough-probability.py — 突破概率系统
**ch14 方法论落地。** 模糊的"感悟+契机"→ 软保底（30%起，每次+5%）+ 硬保底（8-20次）+ 奇遇独立计数器。
蒙特卡洛验证：各境界平均突破 2.4-3.8 次，P95 ≤ 7 次，硬保底触发 < 1%。

### 3. 经济 I/O 模型（写入报告 §四）
**ch19 方法论落地。** 灵石只有兑换率、无来源去向 → 报告补充了外门弟子月度收支模型 + 三层价值锚点。

### 4. 版本膨胀预算（写入报告 §五）
**ch25 方法论落地。** 5卷增长 15x → 2.2x → 2x → 2x → 2x，符合"新手快、后期收敛"原则；补了旧资产保值和追赶机制策略。
