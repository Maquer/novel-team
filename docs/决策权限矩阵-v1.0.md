## 一、问题背景

**核心痛点**：总监AI权限边界模糊，导致决策效率低下。

**具体表现**：
- 质检不通过时，总监不知道该直接退回还是先评估
- 跨部门冲突时，总监不知道该介入还是放权
- 紧急问题时，总监不知道该自主决策还是上报用户

---

## 二、问题分级标准

### 2.1 P0级（阻断性问题）

**定义**：无法继续创作，必须立即解决

**特征**：
- API全部失败（无可用模型）
- 门禁检查全部不通过（无法发布）
- 事实冲突导致逻辑矛盾（无法继续）
- 数据损坏（文件丢失/损坏）

**处理流程**：
```
发现P0级问题
    ↓
立即暂停所有创作
    ↓
30分钟内上报用户
    ↓
等待用户决策
    ↓
执行用户决策
```

**示例**：
- ❌ "API调用失败，无法生成内容"
- ❌ "第5章与第10章事实冲突（主角境界不一致）"
- ❌ "项目配置文件损坏"

---

### 2.2 P1级（严重问题）

**定义**：影响质量但可workaround，需尽快解决

**特征**：
- 部分功能失效（如某个API限流）
- 质量不达标但可修复
- 跨部门协作摩擦
- 进度滞后（<20%）

**处理流程**：
```
发现P1级问题
    ↓
总监自主评估（15分钟内）
    ↓
├─ 可解决 → 执行解决方案，记录日志
└─ 需用户决策 → 2小时内上报
```

**示例**：
- ⚠️ "DeepSeek API限流，切换到备用模型"
- ⚠️ "第3章AI味评分25分（超标），启动修复流程"
- ⚠️ "主笔作者与辅助作者风格不一致，协调标准化"

---

### 2.3 P2级（一般问题）

**定义**：影响效率但不阻塞，可延后处理

**特征**：
- 工具报错但可绕过
- 流程不顺但可完成
- 数据录入不及时
- 建议优化类问题

**处理流程**：
```
发现P2级问题
    ↓
记录日志
    ↓
├─ 4小时内可解决 → 自行解决
└─ 需较长时间 → 汇总到周报，下周处理
```

**示例**：
- ℹ️ "批量改词工具备份功能异常，已手动备份"
- ℹ️ "字数统计脚本输出格式不统一，已修复"
- ℹ️ "建议增加'场景级大纲'功能，已记录到需求池"

---

### 2.4 P3级（轻微问题）

**定义**：建议优化类，可延后处理

**特征**：
- 体验改进建议
- 文档缺失
- 界面不美观
- 效率提升空间

**处理流程**：
```
发现P3级问题
    ↓
记录到需求池
    ↓
月度评审，决定优先级
```

**示例**：
- 💡 "建议增加'创作背景音乐'功能"
- 💡 "日报格式可以更美观"
- 💡 "建议增加'角色关系可视化'"

## 三、决策权限矩阵

### 3.1 总监AI权限

| 问题级别 | 是否可自主决策 | 是否需上报用户 | 响应时间 | 示例决策 |
|---------|--------------|--------------|---------|---------|
| **P0** | ❌ 否 | ✅ 必须 | 30分钟 | "API全失败，建议切换到mock模式继续创作" |
| **P1** | ✅ 是 | ⚠️ 视情况 | 2小时 | "DeepSeek限流，已切换到GLM模型" |

## 四、升级机制

### 4.1 自动升级规则

```
P2级问题 → 4小时未解决 → 自动升级为P1级
P1级问题 → 2小时未解决 → 自动升级为P0级
P0级问题 → 30分钟未解决 → 紧急上报用户
```

### 4.2 降级规则

```
P0级问题 → 用户决策后 → 可按决策降级为P1/P2
P1级问题 → 发现影响较小 → 可降级为P2
```

## 五、执行示例

### 示例1：API失败

**场景**：主笔作者创作时，DeepSeek API限流

**处理流程**：
```
1. 主笔作者发现API限流（P1级）
2. 主笔作者上报总监（5分钟内）
3. 总监评估：DeepSeek限流，但GLM可用
4. 总监自主决策：切换到GLM模型
5. 记录日志："2026-09-27 15:30 DeepSeek限流，已切换到GLM"
6. 通知主笔作者："已切换模型，继续创作"
```

### 示例2：事实冲突

**场景**：审稿编辑发现第5章与第10章主角境界不一致

**处理流程**：
```
1. 审稿编辑发现冲突（P1级）
2. 审稿编辑上报总监（5分钟内）
3. 总监评估：属于严重事实冲突，影响故事逻辑
4. 总监上报用户（30分钟内）
5. 用户决策："修改第10章，补充突破过程"
6. 总监执行：通知世界观师更新事实快照，通知主笔作者修改章节
7. 记录日志："2026-09-27 16:00 事实冲突已修复"
```

### 示例3：建议优化

**场景**：数据分析师建议增加"创作背景音乐"功能

**处理流程**：
```
1. 数据分析师发现优化建议（P3级）
2. 数据分析师记录到需求池
3. 总监月度评审：评估优先级
4. 决定：暂不实施（资源有限）
5. 记录日志："2026-09-27 17:00 需求池新增'创作背景音乐'，暂缓实施"
```
