**风格指纹库**：
```python
DEFAULT_STYLE_FINGERPRINTS = {
    "sentence_patterns": [
        r"[、][^、]{5,15}[、][^、]{5,15}[、]",  # 顿号排比
        r"……",  # 省略号
        r"[！？]{2,}",  # 双标点
    ],
    "vocabulary_preferences": [
```

```bash
  --max-fixes 5 \
```

### 2.3 合同树前置校验（✅ 完成）

**文件**：`tools/outline-precheck.py`（10KB）

**核心功能**：
```python
# 执行前置校验
precheck = OutlinePrecheck("projects/my-novel")
report = precheck.check(strict=False)

# 严格模式（warning升级为error）
report = precheck.check(strict=True)
```

**校验维度**：
1. **大纲结构检查**：章节编号连续性、标题完整性
2. **角色一致性检查**：大纲引用的角色是否已定义
3. **世界一致性检查**：大纲引用的地点是否已定义
4. **伏笔一致性检查**：伏笔的埋设/回收章节是否存在
5. **数值一致性检查**：角色境界跳变检测
6. **潜在风险识别**：未回收伏笔比例、字数目标合理性

**测试用例**：
```bash
# 普通校验
python3 tools/outline-precheck.py check \
  --project projects/my-novel

# 严格校验
python3 tools/outline-precheck.py check \
  --project projects/my-novel \
  --strict
```

**校验报告示例**：

```python
# 预测性分析
prediction = predict_completion_rate(
    chapters_dir="projects/my-novel/chapters",
    min_words=1800,
    days_ahead=7
)
```

**预测指标**：
- **状态**：on_track（达标）/ at_risk（有风险）/ behind（延期）
- **日均产量**：基于已完成章节计算
- **预计完成时间**：单章需要多少天
- **未来7天产量预测**：按当前速率预计能产出多少字

**测试用例**：
```bash
# 基础检查

# 柔性检查（允许±10%偏差）
python3 tools/wordcount-check.py chapter-001.md --flexible

# 带预测分析
python3 tools/wordcount-check.py chapter-001.md --predict

# 批量检查+预测
python3 tools/wordcount-check.py --all --dir projects/my-novel/chapters --predict --days 14
```

**预测输出示例**：
