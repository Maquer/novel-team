# 小说团队 · 创作规范文档 v2.0

> 基于 logic-review.py 逻辑审查门禁 + 世界观硬约束 + 心理描写指引

---

## 一、境界体系（硬约束）

```
淬体期（新手）：搬石→碎砖裂石→无法御气
炼气期（外门）：御气→灵觉初开
筑基期（内门）：御剑飞行→神识外放
金丹期（长老）：一击毁城
元婴期（宗主）：瞬移+近乎无限战力
渡劫期（传说）：大圆满
```

### 能力边界
| 境界 | 可用能力 | 禁用能力 |
|------|---------|---------|
| 淬体 | 肉身力量、基础剑诀 | 御剑飞行、神识、灵气外放 |
| 炼气 | 灵气操控、灵觉 | 凌空飞行、神识扫描 |
| 筑基+ | 御剑、神识 | 瞬移（金丹+） |

## 二、体质体系（硬约束）

### 体质分类

```
传说级（≤1%）：天命体、剑骨
稀有级（5%）：天炎体、玄冰体、煞体
普通级（60%）：金/水/木/土灵体、凡体
特殊级（5%）：无相体、废体
```

### 核心规则
- ❌ 非天命体不可感知天命剑觉醒
- ❌ 非剑骨修炼剑法无加成
- ❌ 煞体修炼正道功法效果减半

## 四、神器规范（硬约束）

### 天命剑设定
- **神器自秽**：伪装成锈铁剑，外人无法识别
- **主角唯一感知**：只有淬体三重萧辰能感知其异动
- **觉醒条件**：生死危机/血脉共鸣
- **代价**：消耗寿命

### 感应规则
- ❌ 淬体/炼气期弟子不可感应神器觉醒
- ❌ 全场景不可"同时感知"
- ✅ 只有主角能隐约感知（心跳漏拍/肌肉反应）

---

## 五、时间线规范（硬约束）

### 章节时间流
```
清晨（天没亮）→ 日出三刻 → 中午 → 傍晚 → 夜晚
```

### 关键节点
- **大比开始**：日出三刻后集合
- **钟声响起**：三长两短
- **尚未发生**：用"即将开始"而非"还没开始"（避免矛盾）

## 六、角色行为规范（软约束）

### 境界→行为匹配
| 境界 | 行为特征 | 示例 |
|------|---------|------|
| 淬体三重 | 坚韧、沉默、观察 | "萧辰充耳不闻，只是继续挥剑" |
| 炼气初期 | 高傲、距离感 | 不主动接触淬体期弟子 |
| 筑基期 | 威严、俯视 | 不直接过问外门事务 |

### 反派行为逻辑
- ❌ 不直接说破秘密（暗示即可）
- ❌ 不正派语气说话（威胁/讽刺/冷漠）
- ✅ 用信息差制造压迫感

## 七、心理描写指引（v2.0 新增）

> 用户反馈「文章直白、像写剧本、全是短篇」的根因之一：
> AI 倾向于用「他想/她觉得」直接告诉读者心理，而非间接展现。
> 本规范提供具体可操作的替换方案。

### 原则：「不写心理，写心理的外在证据」

| 禁止（直白） | 推荐（间接） | 说明 |
|-------------|-------------|------|
| 他想：「我不能输」 | 指节泛白，剑握得更紧 | 动作替代 |
| 她觉得他很危险 | 她下意识后退半步，手已按上剑柄 | 身体反应+动作 |
| 他意识到事情不对 | 他脚步一顿，耳朵捕捉到异常的寂静 | 感官替代 |
| 她心里很恐慌 | 呼吸乱了半拍，喉咙发紧 | 生理反应 |
| 他明白了一切 | 他闭上眼，良久才睁开 | 动作留白 |

### 三种间接心理技术

#### 1. 生理反应（最常用）
```
替代「他想/她感到」→ 描写以下任意一种：
- 手：握拳/颤抖/攥紧/松开/指节泛白
- 心：心跳加速/一沉/猛地一跳/口收紧
- 呼吸：一滞/变急/骤然放缓/屏住
- 脸色：一白/骤变/惨白/涨红
- 眼：瞳孔收缩/猛地放大/微眯/垂下
- 背：发凉/僵硬/紧绷
- 喉：发紧/滚动/微动
- 腿：发软/迈不开步
```

#### 2. 环境投射（次常用）
```
用环境变化反射内心状态：
- 紧张 → 风停了，树叶不动，连虫鸣也消失
- 愤怒 → 窗外的雨突然大了，砸在瓦上噼啪响
- 悲伤 → 天色暗得比平时快，街灯一盏盏亮起
- 释然 → 云层散开，一缕阳光落在脚边
```

#### 3. 回忆闪回（高阶）
```
用回忆替代当前心理活动：
- 「他想起了三年前那个雨夜…」→ 替代「他感到很后悔」
- 闪回要短（1-3句），只给关键画面，不给解释
```

### 反例黑名单（gate-check 自动检测）

| 模式 | 问题 | 修改建议 |
|------|------|---------|
| 「他想/她觉得/他意识到」 | 作者跳出来总结 | 改为生理反应或动作 |
| 「心中/暗地里」 | 同上 | 同上 |
| 同一段情绪词重复≥3次 | 单调 | 换不同角度描写同一情绪 |
| 只写情绪不写证据 | 空泛 | 补生理/环境细节 |

### 心理描写频率参考

| 章节类型 | 心理展现密度 | 说明 |
|---------|-------------|------|
| 过渡章 | 低（每段1处） | 以场景过渡为主 |
| 战斗章 | 极低（0-1处） | 以动作和感官为主 |
| 情感章 | 高（每段2-3处） | 可多用生理反应和环境投射 |
| 揭秘章 | 中（每段1-2处） | 以回忆闪回为主 |

## 八、逻辑审查规则（logic-review.py）

### P0 级（阻断）
1. 时代词汇：办公室/手机/电脑等现代词
2. 境界能力越界：淬体期出现御剑飞行
3. 神器感应越界：非主角感知神器觉醒

### P1 级（警告）
4. 时间线矛盾：开始集合 vs 即将开始
5. 位置行为矛盾：最末尾 vs 最早
6. 门派设定冲突：天剑宗出现阔刀

### P2 级（建议）
7. 因果链漏洞：秘密泄露路径不明确
8. 信息不对称：角色获取信息无合理路径
9. 心理描写直白：「他想/她觉得」模式（psychological_depth 插件检测）

## 九、多线叙事规范（v2.0 新增）

> 解决「多线并行→汇聚时信息不对称/时序混乱」问题

### 叙事线程规则
- 每条角色线独立追踪：主角线/配角线/反派线
- 汇聚章必须所有线同步到达（convergence check）
- 汇聚前的信息不对称需有合理解释（传递路径）
- 某条线中断≥3章 → thread-gap warning

### 汇聚点检查流程
```bash
# 1. 标记汇聚章
python3 tools/narrative-flow.py converge --node-id FN0001 --chapter 15

# 2. 检查信息不对称
python3 tools/narrative-flow.py report --project my-novel
```

### 总编视角（orchestrator-report）
输出内容：
- 各线最新进展章号
- 汇聚章是否所有线到场
- 线程间隙警告（某线超过3章无进展）
- 信息不对称风险（线进度落后汇聚章时）
