## 八、技能使用示例

### 8.1 创作第1章

```bash
# 1. 大纲设计师
python3 tools/outline-builder.py add-chapter \
  --project projects/my-novel \
  --volume-id vol-001 \
  --num 1 \
  --title "开篇" \
  --summary "少年萧辰登场，展现性格，埋下伏笔"

# 2. 主笔作者创作
python3 tools/llm-integrator.py chat \
  --model glm \
  --outline outline/outline.json \
  --world world/world-pack.json \
  --output chapters/chapter-001.md

# 3. 辅助作者扩展
python3 tools/batch-replace-v2.py extend \
  --input chapters/chapter-001.md \
  --target-words 2000 \
  --output chapters/chapter-001-expanded.md

# 4. 质检流程
python3 tools/gate-check.py check --chapter 1 --file chapters/chapter-001-expanded.md
python3 tools/novel-humanizer.py --chapter-file chapters/chapter-001-expanded.md
python3 tools/wordcount-check.py chapters/chapter-001-expanded.md

# 5. 归档
python3 tools/fact-snapshot.py write -c 1 -f changes.json
python3 tools/timeline.py add --event-type chapter_start --chapter 1
```

### 8.2 更新世界包

```bash
# 添加新地点
python3 tools/world-pack.py add-node \
  --type place \
  --id loc-004 \
  --name "天剑宗后山" \
  --parent loc-001

# 添加角色关系
python3 tools/story-graph.py add-edge \
  --from char-001 \
  --to char-002 \
  --type 师兄 \
  --status 尊敬
```

### 8.3 查看系统状态

```bash
# 团队状态
python3 tools/team-launch.py status

# 能力评估
python3 tools/capability-evaluator.py --all --report

# 字数统计
python3 tools/wordcount-check.py --all --dir projects/my-novel/chapters
```
