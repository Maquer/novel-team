## 二、属性四层金字塔落地（ch12）

### 2.1 境界武力值的四层分解

当前 power-model-v3.py 的"最终战力"是单值乘积，不够透明。改用四层结构：

```
最终战力 = 基础战力 × (1 + 功法比例) × (1 + 装备比例) × (1 + 心境比例) × (1 + 实战比例)
```

**每层独立定价、独立控制**：

| 层级 | 当前覆盖 | 需补强项 | 作用 |
|------|---------|---------|------|
| **基础属性**（稳定源） | 境界基准战力（30→50M） | 功法/装备拆分进比例层，基础层只存"同境界同配置下的基准" | 纵向成长 |
| **派生属性** | 功法加成(+%)、装备加成(+) | **缺：暴击/穿透/吸血/控制等战斗规则属性** | 横向构筑 |
| **特殊属性** | 天命剑封印激活 | 需显式声明：哪些属性影响结算顺序（先算比例还是先算加法） | 规则层 |
| **隐藏/控制参数** | 无 | 需补：大境界压制系数(≥2.5x)、小境界递进(1.2-1.5x)、限时增益结算顺序 | 系统控制 |

### 2.2 属性结算公式（ch12核心方法论）

```
实际属性 = 基础值 × (1 + Σ稳定比例修正) + Σ稳定加法修正
最终属性 = 实际属性 × (1 + Σ临时比例修正) + Σ临时加法修正
```

**应用到玄天大陆**：

```
实际战力 = 境界基准 × (1 + 功法加成率) × (1 + 装备加成率)
临时战力 = 实际战力 × (1 + 心境加成率) × (1 + 实战加成率)
最终战力 = 临时战力 × (1 + 大境界压制系数)  [跨境界时用]
```

**当前 power-model-v3.py 的问题**：所有加成混在最后一层相乘，未区分"稳定"与"临时"，导致心境/实战这些可变的临时加成与功法/装备这些稳定加成等同处理。

**修复建议**：v4 分层计算，心境/实战仅在战斗场景注入临时层，日常状态不叠加。

### 2.3 自然数 vs 比例数（ch12 参数设计原则）

| 参数类型 | 当前用法 | 问题 | 修正 |
|---------|---------|------|------|
| 境界战力（自然数） | 淬体四重=100，元婴初期=125,000 | ✅ 适合纵向成长，反馈直观 | 保留 |
| 功法加成（比例数） | 天阶下品=+50% | ✅ 随主体放大，适合横向构筑 | 保留 |
| 装备加成（比例数） | Legendary=+100% | ⚠️ 与功法加成同口径叠加，可能连乘膨胀 | 分属不同"模块"，加前声明"模块内相加，模块间相乘" |
| 心境（比例数） | 轻敌=-15%，绝境爆发=+30% | ✅ 临时属性，战斗时注入 | 保留，但标注"临时层" |
| 大境界压制（自然数系数） | ×2.5 | ⚠️ 这是"控制参数"而非属性，应从公式中独立出来 | 移入隐藏层，单独判断是否触发跨境界压制 |

## 三、概率系统设计（ch14）

### 3.1 境界突破概率

当前设定：`突破条件=境界感悟+瓶颈契机（奇遇/生死危机/悟道）`，**未量化**。

按 ch14 方法论，应明确：

| 机制 | 设计选择 | 对应公式/检查项 |
|------|---------|---------------|
| 突破成功率 | 软保底+硬保底（伪随机） | 连续失败 N 次后概率递增，第 M 次必成功 |
| 保底计数 | 继承/不继承跨场景 | 明确断线、换场景是否重置计数 |
| 失败后果 | 经验损失/时间惩罚/道具消耗 | 用状态转移图建模：每境界=状态，成功/失败/降级=转移边 |
| 体验尾部 | P80/P90 到达时间 | 至少输出：平均/中位突破次数、P90、最坏成本（硬保底次数） |

**推荐方案（符合修仙小说惯例）**：
- 每重/每阶突破：基础成功率 30%，连续失败后每次 +5%（软保底）
- 第 10 次失败后触发硬保底（必成功）
- 失败惩罚：消耗聚气丹 1 颗（或等值灵石），不扣修为
- 奇遇触发：独立事件，不占用保底计数

### 3.2 资源掉落概率（ch14 分层池）

当前妖兽/秘境掉落**未定义概率表**。

按 ch14 "类别→组→物品"分层池设计：

```
掉落结构：
├── 类别1：材料（首通保证）
│   ├── 寒铁（50%）/ 血玉（20%）/ 辟瘴丹草（15%）/ 其他（15%）
├── 类别2：装备（随机）
│   ├── 法器（稀有+）：取决于妖兽阶位
├── 类别3：灵石（保底 1-3 块）
└── 隐藏池：天命剑碎片（0.5%，独立计数器，累计 10 次进入后提升）
```

**检查清单**（ch14 实现与体验检查）：
- [ ] 概率之和 = 100%
- [ ] 保底计数跨端/断线/版本迁移
- [ ] 展示概率 = 后端概率 = 日志记录（三者一致）
- [ ] 识别损失厌恶/赌徒谬误风险

## 四、经济系统设计（ch19）

### 4.1 经济模式选择

当前：系统主导产耗（封闭经济）+ 逍遥阁部分交易（计划经济混合）

按 ch19 决策框架：

| 模式 | 适用场景 | 玄天大陆选择 |
|------|---------|------------|
| 封闭经济 | 强调个人体验，交互弱 | ❌ 不适合（宗门间有贸易） |
| 市场经济 | 玩家自由流通，交互强 | ⚠️ 风险：通胀/垄断/RMT |
| 计划经济 | 系统限制可交易物/渠道/价格 | ✅ 本世界采用 |

**选择理由**：玄幻小说的核心体验是个人成长，非经济博弈；计划经济可防止宗门垄断和资源失衡。

### 4.2 I/O 产耗模型（ch19 核心骨架）

每项资源必须回答：**来源（I）是什么、去向（O）是什么**。

当前仅有灵石价格表，缺完整 I/O 模型。以下为补充设计：

#### 灵石 I/O 模型

```
收入来源（I）：
├── 宗门发放：外门每月 10 下品（系统产出）
├── 任务奖励：10-50 下品/次（系统产出）
├── 妖兽掉落：1-10 下品/次（随机产出）
├── 秘境探索：一次性，100-500 下品（系统产出）
└── 玩家交易：从逍遥阁拍卖行（玩家间流通）

支出去向（O）：
├── 购买丹药：10-100 下品/颗
├── 购买装备：50-500 下品
├── 购买功法残卷：200-1000 下品
├── 突破丹药消耗：聚气丹 50 下品/颗
└── 交易手续费：5%（逍遥阁抽成）
```

#### 核心检查项（ch19 构建检查）

1. ✅ 每项资源有稳定来源（宗门+任务+掉落）
2. ✅ 每项资源有稳定退出（消费+损耗）
3. ✅ 玩家何时短缺：炼气期突破前（聚气丹刚需）
4. ✅ 何时过剩：筑基后（灵石购买力下降，转向中品）
5. ⚠️ 闭环套利风险：逍遥阁拍卖行手续费 5%，理论上可低买高卖；需在设定中限制"绑定/不可交易"物品比例

### 4.3 价值锚点体系（ch19）

建立三层换算链，避免"以商店价格为唯一锚点"的反模式：

| 锚点层级 | 单位 | 换算 | 用途 |
|---------|------|------|------|
| 货币层 | 下品灵石 | 100 下品 = 1 中品 = 10000 下品 | 日常交易 |
| 时间层 | 修炼时间 | 100 下品 ≈ 外门弟子 10 天工资 | 评估性价比 |
| 战力层 | 战力值 | 1000 下品 ≈ 提升 1 点战斗力（估算） | 战斗决策 |

**反模式规避**：不直接用商店价格判断丹药价值，用"修炼时间×月工资"作为真实成本基准。

## 五、版本膨胀预算（ch25）

### 5.1 当前设定 vs ch25 检查

| 检查项 | 当前状态 | ch25 要求 | 结论 |
|--------|---------|----------|------|
| 战力增长上限 | 淬体 30→渡劫 50,000,000 | 需定义年度/赛季总预算 | ⚠️ 缺失 |
| 旧资产保值 | 无明确机制 | 新内容不应淘汰旧内容 | ❌ 缺失 |
| 追赶机制 | 无 | 新/回归玩家如何接近主流 | ❌ 缺失 |
| 5卷路线图 | 有（project-config.json） | 需含成长预算/资源预算/风险余量 | ⚠️ 不完整 |

### 5.2 5卷膨胀预算（基于当前境界战力表）

```
卷1（开篇·淬体篇）：战力 30-450    增长 15x（新手期可接受较高倍率）
卷2（外门·炼气篇）：战力 1,000-2,200  增长 2.2x
卷3（内门·筑基篇）：战力 5,000-10,000 增长 2x
卷4（宗门·金丹篇）：战力 25,000-50,000 增长 2x
卷5（大陆·元婴篇）：战力 125,000-250,000 增长 2x
```

**复利速度检查**（72法则）：
- 卷2→卷3：每卷增长 ~2.27x → 翻倍需 72/127 ≈ 0.6 卷（实际跨卷，合理）
- 卷4→卷5：每卷增长 ~2.5x → 翻倍需 72/125 ≈ 0.58 卷（合理）
- 总体：淬体→元婴 = 555x，跨 4 个大境界，符合"每大境界 ×2.5"设定

### 5.3 旧资产保值策略（ch25）

当前缺此项。建议引入：

| 旧资产 | 新卷中保值方式 |
|--------|--------------|
| 淬体期功法（凡阶/黄阶） | 转为"基础功法"定位，仍可用于战斗，但不作为突破依赖 |
| 低阶灵石储备 | 高境界后贬值，用"中品灵石"切换锚点，而非直接作废 |
| 外门弟子身份 | 新卷中转化为"人脉/情报"价值，非纯战力指标 |

### 5.4 追赶机制（ch25）

```
目标：新/回归玩家可在 3-5 章内接近当前主流进度

工具组合：
├── 等级差经验加成：低境界对手给予额外经验值（上限 200%）
├── 旧材料增产：低阶材料在高境界区域仍有产出，但量减少
├── 回归任务：一次性资源礼包（最多价值 1000 下品灵石）
└── 阶段跳过：跳过已完成的低级秘境，直接进入高级
```

**防滥用**：
- 追赶资源有使用期限（30 天游戏时间）
- 不直接送满境界，只送"接近"的资源
- 机器人检测：异常快速获取资源触发人工审核
