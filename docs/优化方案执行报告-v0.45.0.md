### 2.3 记忆压缩机制（P0级优化）

**问题背景**：
- 主笔作者上下文管理成本高，token消耗大
- 每创作一章都要重新加载大量数据
- 冗余信息占用过多token

**解决方案**：
- 增加"记忆压缩"功能到`context-manager.py`
- 分类处理：关键信息完整保留、重要信息压缩保留、一般信息转摘要
- 目标压缩率：≤60%（减少40%以上的token消耗）

**交付物**：
- `tools/context-manager.py`（已更新，19KB）

**核心功能**：
```python
def compress_context(self, context: Dict, target_length: int = None) -> Dict:
    """
    记忆压缩机制（v0.45.0新增）
    
    核心逻辑：
    1. 分类：将上下文内容按重要性分级
    2. 保留：关键信息完整保留
    3. 压缩：重要信息按比例压缩
    4. 丢弃：一般信息和噪声丢弃
    """
```

### 2.4 柔性门禁检查（P1级优化）

**问题背景**：
- 审稿编辑门禁检查过于僵化
- 合理创作被误判（如字数略不足）
- 缺乏灵活性导致返工

**解决方案**：
- 新建`gate-check.py`，支持柔性模式
- 区分"刚性门禁"（事实冲突等）和"柔性门禁"（字数偏差等）
- 柔性模式下，warning不阻塞通过，但记录在案

**交付物**：
- `tools/gate-check.py`（新建，11KB）

**核心配置**：
```python
GATE_CONFIG = {
    "word_count": {
        "enabled": True,
        "min_words": 1800,
        "max_words": 2200,
        "flexible_range": 0.10,  # 允许±10%偏差
        "critical": True  # 刚性门禁
    },
    "ai_tone": {
        "enabled": True,
        "max_score": 15,
        "flexible_range": 0.05,  # 允许≤5分偏差
        "critical": True
    }
}
```
