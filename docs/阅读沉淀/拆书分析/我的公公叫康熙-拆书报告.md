## 三、七维知识提取

### 2.1 世界观设定（World）

**时代背景**：
- 时间：康熙三十七年（1698年）
- 地点：京城，西城董鄂伯府
- 历史时期：清朝康熙盛世

**社会结构**：
```
八旗制度
├─ 八旗（满洲、蒙古、汉军、包衣）
│   ├─ 正红旗（董鄂家所属）
│   ├─ 镶黄旗（郭络罗家所属）
│   └─ ...
├─ 等级体系
│   ├─ 宗室（皇帝族亲）
│   ├─ 勋贵（董鄂家）
│   ├─ 官员
│   └─ 普通旗民
└─ 特殊群体
    ├─ 包衣（奴隶出身，后抬旗）
    └─ 旗人（军民合一）
```

**经济体系**：
- 银楼：金银首饰加工销售
- 茶庄：茶叶采购销售（杭州龙井、苏州碧螺春等）
- 货币：银两、铜钱

**关键设定**：
- ✅ 八旗制度是军制+户籍制
- ✅ 佐领是基本单位（100户）
- ✅ 都统是一旗最高长官
- ✅ 旗人之间分等级（宗室>勋贵>官员>普通旗民）

**基本信息**：
- 身份：董鄂家大格格（长女）
- 年龄：16岁
- 特质：穿越者（现代灵魂）
- 能力：商业头脑、法律意识、政治敏感度

**外貌特征**：
- 身高：近1米7（在清代女性中算高）
- 体型：消瘦（选秀时瘦了十斤）

**性格特点**：
- 精明强干（经营银楼、茶庄）

- 孝顺懂事（关心家人）

**核心目标**：

### 2.3 情节设定（Plot）

#### 主线剧情

**核心冲突**：
```
郭络罗家（宜妃娘家）
    ↓ 想强买
顺安银楼（舒舒私产）
    ↓ 舒舒反击
放钩子→拿证据→打官司
    ↓
九阿哥卷入（幕后黑手）
```

**剧情节奏**：
- 第1章：引入冲突（银楼被告→官府调解）

- 第3章：官府对峙（衙门相遇九阿哥）

#### 支线剧情

**经商线**：

## 三、可借鉴要点

### 3.1 命名借鉴

**主角命名**：
- 舒舒（叠字亲切，适合女性主角）
- 现代感+历史感的平衡

**配角命名**：
- 福松、珠亮（满族风格）
- 齐锡、觉罗氏（旗人家庭）

**反派命名**：
- 郭络罗桂丹（满姓+汉族名，体现包衣身份）
- 王大（底层爪牙，普通名字）

**命名规律总结**：
1. 主角用叠字名（亲切、易记）
2. 旗人角色用满姓（董鄂、郭络罗、觉罗）
3. 反派名有暗示性（桂丹→平庸）
4. 底层角色用普通名（王大）

**商业细节**：

**借鉴方法**：

- 用细节推动剧情发展

### 3.3 冲突设计借鉴

**冲突层次**：
```
第一层：内部管理（王大贪污）
    ↓
第二层：外部竞争（郭络罗强买）
    ↓
第三层：政治博弈（九阿哥介入）
    ↓
第四层：家族危机（官非影响名声）
```

**冲突升级**：
- 先内部后外部
- 先商业后政治
- 先个人后家族

**解决方式**：
- 不靠武力靠智慧
- 不靠关系靠法律
- 不靠运气靠布局

---

### 3.4 节奏控制借鉴

**章节节奏**：
- 开头：引入冲突（银楼被告）
- 中间：展开细节（家庭、经商、布局）
- 结尾：留下悬念（九阿哥登场）

**信息密度**：
- 每章有新信息（制度、人物、剧情）
- 不急于推进，注重铺垫
- 读者能跟上节奏

**情绪曲线**：
- 平静（日常经营）→ 担忧（内部问题）→ 愤怒（外部打压）→ 期待（反击布局）

## 五、对我们的启示

### 5.1 命名建议

**对于《天命》**：
- ✅ 可以参考"舒舒"式命名（亲切感）
- ✅ 也可以用"萧辰"式命名（霸气感）
- ⚠️ 避免"张三李四"式命名（太随意）

**建议方案**：
- 主角：萧辰（霸气）或 萧辰儿（亲切）
- 师兄：苏逸（洒脱）
- 反派：王傲天（傲慢）

### 5.2 细节描写建议

**可以借鉴**：
- ✅ 增加修炼细节（功法、境界、资源）
- ✅ 增加环境描写（宗门、山脉、气候）
- ✅ 增加饮食描写（丹药、灵茶、兽肉）
- ✅ 增加服饰描写（弟子服、长老袍）

**需要注意**：
- ⚠️ 不要过于冗长（影响节奏）
- ⚠️ 不要脱离主线（细节服务剧情）
- ⚠️ 不要重复累赘（精选典型细节）

### 5.3 冲突设计建议

**可以借鉴**：
- ✅ 多层冲突设计（内部→外部→政治）
- ✅ 冲突层层升级（小矛盾→大危机）
- ✅ 用智慧解决（非纯武力）

**需要注意**：
- ⚠️ 节奏要快（不要铺垫太长）
- ⚠️ 开篇要有钩子（不要平淡开头）
- ⚠️ 冲突要具体（不要抽象概括）
