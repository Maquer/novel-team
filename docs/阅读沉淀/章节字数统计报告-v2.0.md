```json
{

    "target": 2500,
    "soft_min": 2000,
```

## 五、结论

### 5.1 核心发现

1. **主流网文单章字数在2,000-3,000字之间**，中位数约2,500字
2. **快节奏爽文可接受1,500字左右**，但不应低于1,200字
3. **慢节奏细节文建议3,000字以上**，但超过5,000字可能拖沓
4. **当前门禁配置（hard=1500, soft=2000, target=2500, warn=3500）合理**

### 5.2 建议

1. ✅ **保持现有门禁配置**——与实测数据吻合
2. ⏳ **后续可优化**——按题材类型设置不同阈值
3. ⏳ **持续积累样本**——抓取更多热门小说验证

1. **单一实测样本**：仅《我的公公叫康熙》有实测数据
