## 三、门禁阈值建议

基于实测数据，建议三级阈值：

| 级别 | 字数下限 | 判定逻辑 | 适用场景 |
|------|---------|---------|---------|
| **hard_min** | 1500字 | P0阻断，低于必须重写 | 快节奏爽文可放宽 |
| **soft_min** | 2000字 | P1警告，低于提示扩充 | 主流剧情文要求 |
| **target** | 2500字 | 写作目标，达标即合格 | 中节奏剧情文 |
| **warn_above** | 3500字 | P2提示，高于考虑拆分 | 慢节奏文可放宽 |

**当前配置已生效**：
```json
{
  "word_count": {
    "target": 2500,
    "soft_min": 2000,
    "hard_min": 1500,
    "warn_above": 3500
  }
}
```
