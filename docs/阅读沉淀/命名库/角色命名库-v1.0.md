## 一、主角命名库（已修正·2026-09-27）

> **修正原因**：原方案"逸尘、轩辕、凌天"等名字网文风太重，不够真实
> **核心原则**：主角名要像真人名，不能像从套路里掏出来的

### 1.1 主角命名原则

**核心原则**：
- ✅ 普通的人名，像现实中会取的名字
- ✅ 有记忆点但不夸张
- ✅ 符合角色身份和时代背景
- ❌ 不用"逸尘、轩辕、凌天、星辰、风云"等网文套路名
- ❌ 不用"龙傲、天霸、影杀、夜煞"等中二名字

**头部作品参考**：
```
《斗破苍穹》：萧炎（简单直接）
《凡人修仙传》：韩立（极其普通）
《遮天》：叶凡（普通中见不凡）
《完美世界》：石昊（大气但不夸张）
《斗罗大陆》：唐三（普通简洁）
```

### 1.2 正确的主角名示例

**简约型**（推荐）：
```
- 萧辰（简单好记，有气势）
- 叶凡（普通中见不凡）
- 林动（灵动有力）
- 石昊（大气磅礴）
- 周青（简洁有力）
```

**普通型**（更真实）：
```
- 陈凡（极其普通，像身边人）
- 李凡（普通姓氏+普通名）
- 张毅（普通但有力量感）
- 王刚（普通到不像主角）
- 刘伟（普通到路人水平）
```

**避免的名字**：
```
❌ 逸尘、轩辕、寒渊、凌天、星辰、风云
❌ 龙傲、天霸、尘凡、墨染、影杀
❌ 夜煞、天枭、战天、问天
❌ 任何读起来像"小说名"的组合
```

### 1.3 命名公式（已修正）

**公式1：普通姓+普通名**
```
✅ 萧辰（常见姓+常见名）
✅ 叶凡（常见姓+常见名）
✅ 韩立（常见姓+常见名）
```

**公式2：少见姓+普通名**
```
✅ 林动（少见姓+普通名）
✅ 石昊（少见姓+大气名）
✅ 周青（少见姓+简洁名）
```

**公式3：普通姓+有意境名**
```
✅ 陈深渊（普通姓+有深度的名）
✅ 李长风（普通姓+有意境的名）
✅ 张独行（普通姓+有性格的名）
```

## 三、反派命名库（已修正·2026-09-27）

> **修正原因**：原方案"煞、魔、霸"等字眼太套路，不符合真实逻辑
> **核心原则**：反派是普通人，不是靠名字看出来的

### 3.1 命名原则

**核心原则**：
- ✅ 用普通人名 + 职衔/身份
- ❌ 不用"煞、魔、霸、血"等夸张字眼
- ❌ 不用"傲天、无敌"等中二名字
- ✅ 通过行为和经历展现反派特质
- ✅ 给反派合理的动机

### 3.2 正确的反派命名方式

**方式一：职衔+名字**
```
示例：
- 王执事（外门执事）
- 李长老（内门长老）
- 张管事（商会管事）
- 赵峰主（山峰峰主）
- 孙堂主（某堂堂主）
```

**方式二：普通人名+身份暗示**
```
示例：
- 王师兄（同门师兄，嫉妒主角）
- 李公子（某家族公子，利益冲突）
- 张少爷（某商会长子，竞争关系）
```

**方式三：用外貌和行为刻画反派特质**
```
示例：
- 面容严肃的中年人（王执事）
- 眼神冰冷的青年（李师兄）
- 笑面相迎的老者（张管事）
```

### 3.3 《天命》反派设计

**第一卷（底层→中层）**：
```
王大（底层爪牙）
- 普通人名，无存在感
- 外门弟子，欺凌主角的打手

王执事（中层反派）
- 表面和善，实际精于算计
- 维护宗门秩序，视主角为不稳定因素

李师兄（中层反派）
- 嫉妒主角天赋，担心地位被取代
- 笑容满面但眼神闪躲
```

**第二卷（中层→高层）**：
```
孙长老（中层反派）
- 表面慈眉善目，实际心狠手辣
- 资源争夺，视主角为竞争对手

血无痕（高层大佬）
- 有气势的名字，压迫感
- 某势力长老，实力强大
- 名字本身就是威慑
```

**第三卷（高层→终极）**：
```
阴九幽（高层大佬）
- 有气势的名字，神秘威严
- 某宗门太上长老，幕后黑手

厉天霸（终极BOSS候选）
- 有气势的名字，霸气外露
- 某殿主，最终决战对象

血衣侯（终极BOSS）
- 称号，神秘威严
- 最终反派，压迫感极强
```

### 3.4 分层命名策略（新增·2026-09-27）

**核心原则**：根据角色地位分层命名

| 层级 | 命名方式 | 示例 | 作用 |
|------|---------|------|------|
| **底层爪牙** | 普通人名 | 王大、李四、张旺 | 路人感，无存在感 |
| **中层反派** | 职衔+普通名 | 王执事、李长老、张管事 | 有地位感，真实感 |
| **高层大佬** | 有气势的名字 | 血无痕、阴九幽、厉天霸 | 压迫感，记忆点 |
| **终极BOSS** | 称号/代号 | 血衣侯、阴煞尊者、天霸殿主 | 神秘感，威慑力 |

**示例**：
```
《天命》反派层级：

第一卷（底层→中层）：
- 王大（外门弟子，欺凌主角的打手）
- 王执事（外门执事，表面和善实际精明）
- 李师兄（同门师兄，嫉妒主角天赋）

第二卷（中层→高层）：
- 孙长老（内门长老，资源争夺者）
- 张管事（商会管事，利益驱动）
- 血无痕（某势力长老，有气势的名字）

第三卷（高层→终极）：
- 阴九幽（某宗门太上长老，压迫感）
- 厉天霸（某殿主，终极BOSS候选）
- 血衣侯（称号，神秘威严）
```

## 五、命名禁忌

### 5.1 避免的命名

**过于常见的**：
- ❌ 张三、李四、王五（打酱油三人组）
- ❌ 张伟、王芳、李娜（现实中太多）
- ❌ 龙傲天（网络梗，慎用）

**过于中二的**：
- ❌ 灭世、诛神、弑天（除非是搞笑文）
- ❌ 寂寞、空虚、冷（过于矫情）

**过于复杂的**：
- ❌ 欧阳司马、端木铜铁（念都念不过来）
- ❌ 生僻字（读者不认识）
