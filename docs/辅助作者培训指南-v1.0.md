# 小说团队 · 辅助作者培训指南

> 版本：v1.0
> 制定时间：2026-09-27
> 状态：✅ 生效
> 负责人：主笔作者AI

---

## 一、培训目标

**核心目标**：缩小主笔作者与辅助作者的质量差距，提升批量创作的一致性。

**具体指标**：
- AI味评分≤15分（与主笔作者同等标准）
- 字数达标率≥95%
- 门禁通过率≥85%
- 风格一致性≥80%（主笔作者评分）

---

## 二、培训阶段

### 阶段1：文风学习（第1周）

**目标**：理解并模仿主笔作者的文风

**学习内容**：
1. **示范章节分析**
   - 阅读主笔作者的5个示范章节
   - 标注：句式特点、词汇偏好、节奏控制、对话风格
   - 输出：《文风分析报告》

2. **风格要素提取**
   - 句式：长句/短句比例、复合句使用频率
   - 词汇：禁用词表、高频词表、专业术语
   - 节奏：段落长度、场景切换频率、高潮分布
   - 对话：引号使用、对话占比、旁白比例

3. **仿写练习**
   - 提供3个大纲片段
   - 辅助作者仿写（每段300字）
   - 主笔作者评分（1-10分）
   - 反馈修正，直到≥7分

**验收标准**：
- ✅ 文风分析报告完整
- ✅ 3个仿写片段平均分≥7分
- ✅ 通过"风格测试"（盲测：主笔作者无法区分辅助作者与自己的作品）

---

### 阶段2：工具熟练使用（第2周）

**目标**：掌握所有必备工具，提升效率

**学习工具**：
1. **batch-replace-v2.py**
   - 批量替换专有名词
   - 预览模式确认
   - 自动备份机制

2. **wordcount-check.py**
   - 字数统计
   - 达标判断
   - 不足时的扩展策略

3. **clean_commas.py + inject_punctuation.py**
   - 脏逗号清理
   - 标点注入（番茄风格）

4. **merge-chapters.py**
   - 章节合并
   - 格式标准化

**练习任务**：
- 使用batch-replace-v2.py替换10个专有名词（准确率100%）
- 使用wordcount-check.py统计20章字数（误差<5%）
- 使用clean_commas.py清理5章（清理率>90%）

**验收标准**：
- ✅ 工具使用测试通过（10题全对）
- ✅ 效率达标（单章处理<10分钟）

---

### 阶段3：实战演练（第3周）

**目标**：独立完成完整章节创作

**实战任务**：
1. **第1周**：每天创作1章，主笔作者逐章review
2. **第2周**：每天创作2章，主笔作者抽查1章
3. **第3周**：每天创作3章，主笔作者仅看门禁报告

**反馈机制**：
- 每章创作后，主笔作者提供反馈（3个优点+2个改进点）
- 辅助作者根据反馈调整
- 连续3章无明显问题，进入下一阶段

**验收标准**：
- ✅ 门禁通过率≥85%
- ✅ AI味评分≤15分
- ✅ 主笔作者评分≥7分

---

### 阶段4：独立认证（第4周）

**目标**：获得独立创作资格

**认证测试**：
1. **盲测**：5个章节，混入主笔作者的2个章节
2. **评分**：主笔作者评分，区分准确率需<70%（即难以区分）
3. **质量检查**：门禁通过率、AI味评分、字数达标率
4. **风格一致性**：主笔作者评分风格匹配度

**认证通过标准**：
- ✅ 盲测区分准确率<70%
- ✅ 门禁通过率≥90%
- ✅ AI味评分≤15分
- ✅ 风格一致性≥80%

**认证结果**：
- 通过：获得"独立创作资格"，日产量提升至5章
- 未通过：延长培训1周，重新认证

## 三、日常质量保障

### 3.1 创作前检查

```bash
# 辅助作者每日创作前执行
python3 tools/gate-check.py --check-myself  # 自我预检
python3 tools/novel-humanizer.py --check --dry-run  # AI味预检
```

### 3.2 创作中约束

| 约束项 | 规则 | 检查方式 |
|--------|------|---------|
| **字数** | 每章≥1800字 | wordcount-check.py |
| **AI味** | 评分≤15分 | novel-humanizer.py |
| **事实** | 不违反已有设定 | fact-snapshot.py check |
| **风格** | 符合主笔作者风格 | 主笔作者抽检 |

### 3.3 创作后审核

```bash
# 辅助作者创作后自动执行
python3 tools/gate-check.py check --chapter $N
python3 tools/novel-humanizer.py check --file chapter-$N.md
python3 tools/wordcount-check.py chapter-$N.md
```

## 四、考核与淘汰

### 4.1 月度考核

| 指标 | 合格线 | 优秀线 | 权重 |
|------|--------|--------|------|
| 门禁通过率 | ≥85% | ≥95% | 30% |
| AI味评分 | ≤15分 | ≤10分 | 25% |
| 字数达标率 | ≥95% | 100% | 20% |
| 风格一致性 | ≥75% | ≥90% | 15% |
| 生产效率 | ≥3章/天 | ≥5章/天 | 10% |

**综合评分**：加权平均

**考核结果**：
- ≥90分：优秀，奖励（优先创作关键章节）
- 75-89分：合格，继续独立创作
- 60-74分：观察，减少产量至2章/天
- <60分：淘汰，重新培训或调岗

### 4.2 淘汰机制

**触发条件**（满足任一）：
- 连续2月度考核<60分
- 单章AI味评分>30分
- 单章字数<1500字
- 事实冲突导致故事逻辑错误

**淘汰流程**：
```
触发淘汰条件
    ↓
总监评估（是否可挽救）
    ↓
├─ 可挽救 → 重新培训1周
└─ 不可挽救 → 调岗（转辅助岗）或退出团队
```

## 五、激励措施

### 5.1 晋升机制

| 等级 | 条件 | 待遇 |
|------|------|------|
| **见习作者** | 培训中 | 日产量1-2章 |
| **助理作者** | 通过认证 | 日产量3章 |
| **独立作者** | 连续3月优秀 | 日产量5章 + 优先选章 |
| **资深作者** | 连续6月优秀 + 风格测试通过率>90% | 日产量8章 + 可指导新人 |

### 5.2 奖励机制

- **月度优秀**：优先创作关键章节（开篇、高潮、结局）
- **季度优秀**：额外培训资源（如文风大师课）
- **年度优秀**：晋升为"主笔作者候选人"
