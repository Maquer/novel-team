## 五、启动风险与应对

### 5.1 潜在风险

| 风险 | 影响 | 应对方案 |
|------|------|---------|
| API调用失败 | 无法生成内容 | 使用mock模式，后续接入真实API |
| 门禁检查不通过 | 需要反复修改 | 柔性门禁，允许带病运行 |
| 去AI味过度 | 破坏原文风格 | 设置修复上限，人工复核 |
| 事实冲突 | 逻辑矛盾 | 增强预检机制 |
| 进度滞后 | 影响发布计划 | 每日站会，及时调整 |

### 5.2 降级方案

**如果API不可用**：
```bash
# 使用模拟模式继续创作
export LLM_MODE="mock"
python3 tools/llm-integrator.py chat --model glm --prompt "..."
```

**如果门禁不通过**：
```bash
# 使用柔性模式（允许警告通过）
python3 tools/gate-check.py check --chapter 1 --flexible
```

**如果去AI味过度**：
```bash
# 限制修复数量
python3 tools/novel-humanizer.py --max-fixes 3 --file chapter.md
```
