## 一、项目启动流程（第一步）

### 1.1 启动检查（3分钟完成）

```bash
cd /var/minis/shared/novel-team

# 1. 查看团队状态（30秒）
python3 tools/team-launch.py

# 2. 查看项目配置（30秒）
cat projects/my-novel/project-config.json

# 3. 查看大纲框架（30秒）
python3 tools/outline-builder.py --project projects/my-novel tree

# 4. 查看世界包状态（30秒）
python3 tools/world-init.py --project projects/my-novel stats

# 5. 查看待办任务（30秒）
python3 tools/team-manager.py status
```

### 1.2 启动决策（选择启动方式）

| 启动方式 | 适合场景 | 第一步操作 |
|---------|---------|-----------|
| **稳健型** | 追求高质量 | `先完善世界包` |
| **快速型** | 想尽快看到成果 | `开始创作第1章` |
| **敏捷型** | 快速验证方向 | `写500字试水` |
| **规划型** | 追求完美规划 | `制定30天计划` |

### 1.3 启动后即时行动

```bash
# 创建项目日志
mkdir -p projects/my-novel/logs
echo "## 项目启动日志" > projects/my-novel/logs/startup.log
echo "- 启动时间：$(date)" >> projects/my-novel/logs/startup.log
echo "- 启动方式：[选择A/B/C/D]" >> projects/my-novel/logs/startup.log
echo "- 负责人：总监AI" >> projects/my-novel/logs/startup.log
```

## 二、团队成员协作机制

### 2.1 协作原则

```
┌─────────────────────────────────────────────────────────────┐
│  1. 信息透明：所有决策和变更必须记录                          │
│  2. 及时同步：问题发现后30分钟内上报                          │
│  3. 责任明确：每个任务有唯一负责人                            │
│  4. 流程规范：严格按照SOP执行                                 │
│  5. 持续改进：每周复盘，优化流程                              │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 日常协作流程

#### 早间同步（09:00，5分钟）

```bash
# 数据分析师生成日报
python3 tools/wordcount-check.py --report daily

# 团队总监主持晨会
echo "【晨会】$(date)" >> projects/my-novel/logs/daily.log
echo "参与人：全员" >> projects/my-novel/logs/daily.log
echo "议题：1.昨日进度 2.今日计划 3.风险预警" >> projects/my-novel/logs/daily.log
```

#### 创作协作（10:00-17:00）

**章节创作流程图**：
```
大纲设计师 ──→ 主笔作者 ──→ 辅助作者
    ↓              ↓              ↓
 大纲定稿        初稿生成        续写扩展
    ↓              ↓              ↓
    └──────────→ 审稿编辑 ←────────┘
                    ↓
              去AI味师
                    ↓
              数据分析师
                    ↓
              世界观师
                    ↓
              团队总监
                    ↓
                 发布
```

**各角色具体操作**：

| 角色 | 操作命令 | 输出物 | 时长 |
|------|---------|--------|------|
| 大纲设计师 | `outline-builder add-chapter` | 章节大纲.md | 15分钟 |
| 主笔作者 | `llm-integrator chat` | 初稿.md | 30分钟 |
| 辅助作者 | `batch-replace --preview` | 续写稿.md | 20分钟 |
| 审稿编辑 | `gate-check check` | 检查报告.md | 10分钟 |
| 去AI味师 | `novel-humanizer check` | 优化稿.md | 15分钟 |
| 数据分析师 | `wordcount-check` | 统计报告.md | 5分钟 |
| 世界观师 | `fact-snapshot write` | 快照.json | 10分钟 |
| 团队总监 | `contract-tree check` | 校验报告.md | 10分钟 |

#### 晚间汇总（18:00，10分钟）

```bash
# 数据分析师生成日报
python3 tools/wordcount-check.py --report daily --output projects/my-novel/logs/daily-report.md

# 团队总监审核
cat projects/my-novel/logs/daily-report.md

# 记录日志
echo "【日报】$(date)" >> projects/my-novel/logs/daily.log
echo "完成章节：X章" >> projects/my-novel/logs/daily.log
echo "总字数：X字" >> projects/my-novel/logs/daily.log
echo "问题数：X个" >> projects/my-novel/logs/daily.log
```

## 三、问题发现与解决流程

### 3.1 问题分级标准

| 级别 | 定义 | 响应时间 | 升级机制 |
|------|------|---------|---------|
| **P0** | 阻断性问题，无法继续创作 | 立即 | 直接上报总监 |
| **P1** | 严重问题，影响质量但可 workaround | 30分钟 | 1小时未解决升级 |
| **P2** | 一般问题，影响效率 | 4小时 | 次日处理 |
| **P3** | 轻微问题，建议优化 | 本周内 | 周报汇总 |

### 3.2 问题上报模板

```markdown
## 问题上报

- **问题ID**：bug-YYYYMMDD-NNN
- **发现时间**：YYYY-MM-DD HH:MM
- **发现人**：[角色姓名]
- **问题级别**：P0/P1/P2/P3
- **问题描述**：
  [详细描述问题]
- **影响范围**：
  [受影响的章节/功能]
- **临时解决方案**：
  [如有]
- **期望解决时间**：
  [根据级别设定]
```

### 3.3 常见问题及解决方案

#### 问题1：API调用失败

**现象**：
```
Error: API timeout or rate limit exceeded
```

**解决方案**：
```bash
# 方案A：检查API状态
python3 tools/llm-integrator.py --status

# 方案B：切换到备用模型
python3 tools/llm-integrator.py chat --model deepseek

# 方案C：使用mock模式继续创作
export LLM_MODE="mock"
python3 tools/llm-integrator.py chat --model glm

# 方案D：等待后重试（自动退避）
sleep 60
python3 tools/llm-integrator.py chat --model glm
```

**责任人**：主笔作者 → 团队总监

---

#### 问题2：门禁检查不通过

**现象**：
```
Gate Check Failed: 
- Word count too short (1500 < 1800)
- AI tone score too high (25 > 15)
```

**解决方案**：
```bash
# 方案A：查看详细问题
python3 tools/gate-check.py check --chapter 1 --verbose

# 方案B：使用柔性模式（允许警告通过）
python3 tools/gate-check.py check --chapter 1 --flexible

# 方案C：针对性修复
# 字数不足 → 辅助作者续写
python3 tools/batch-replace.py --action extend --words 300

# AI味过高 → 去AI味师优化
python3 tools/novel-humanizer.py --fix --max-fixes 5
```

**责任人**：审稿编辑 → 去AI味师 → 主笔作者

---

#### 问题3：事实冲突

**现象**：
```
Fact Conflict Detected:
- Character realm changed without update
- Location missing from snapshot
```

**解决方案**：
```bash
# 方案A：查看详细冲突
python3 tools/fact-snapshot.py --project 天命 check

# 方案B：手动修复
python3 tools/fact-snapshot.py --project 天命 write \
  -c 1 \
  -f fixes.json

# 方案C：回滚到上一版本
python3 tools/fact-snapshot.py --project 天命 rollback --chapter 1
```

**责任人**：世界观师 → 大纲设计师

---

#### 问题4：进度滞后

**现象**：
```
Weekly Target: 10 chapters
Actual: 3 chapters
Status: BEHIND SCHEDULE
```

**解决方案**：
```bash
# 方案A：分析原因
python3 tools/wordcount-check.py --report weekly --analyze

# 方案B：调整计划
python3 tools/outline-builder.py --project projects/my-novel \
  reschedule --target 5 --week 2

# 方案C：增加资源
# 临时调配辅助作者支持
echo "增加辅助作者支持" >> projects/my-novel/logs/decision.log

# 方案D：降低标准（临时）
export QUALITY_MODE="fast"
```

**责任人**：团队总监 → 数据分析师

---

#### 问题5：质量不达标

**现象**：
```
Quality Score: 65/100
Target: 85/100
Gap: -20 points
```

**解决方案**：
```bash
# 方案A：详细评估
python3 tools/capability-evaluator.py --module quality --detailed

# 方案B：针对性优化
# 情节问题 → 剧情推演
python3 tools/plot-simulation-v2.py simulate --chapter 1

# 人物问题 → 角色档案
python3 tools/story-graph.py add-node --type character

# 节奏问题 → 剧情分析
python3 tools/plot-analyzer.py --chapter 1 --fix pace

# 方案C：重新创作
python3 tools/llm-integrator.py chat --chapter 1 --regen
```

**责任人**：审稿编辑 → 主笔作者 → 去AI味师

## 六、启动命令速查

### 6.1 项目启动（第一次）

```bash
# 1. 进入项目目录
cd /var/minis/shared/novel-team

# 2. 查看团队状态
python3 tools/team-launch.py

# 3. 确认项目配置
cat projects/my-novel/project-config.json

# 4. 初始化项目日志
mkdir -p projects/my-novel/logs
echo "# 项目启动日志" > projects/my-novel/logs/startup.log
echo "- 启动时间：$(date)" >> projects/my-novel/logs/startup.log
echo "- 启动方式：稳健启动" >> projects/my-novel/logs/startup.log

# 5. 开始第1步：完善世界包
python3 tools/world-init.py init --project projects/my-novel --name "玄天大陆"
```

### 6.2 日常创作循环

```bash
# 每天重复以下流程：

# 早间同步（09:00）
python3 tools/team-launch.py
python3 tools/team-manager.py status

# 创作循环（10:00-17:00）
for chapter in 1 2 3; do
  # 1. 大纲设计
  python3 tools/outline-builder.py add-chapter --project projects/my-novel --num $chapter
  
  # 2. LLM创作
  python3 tools/llm-integrator.py chat --model glm --chapter $chapter
  
  # 3. 门禁检查
  python3 tools/gate-check.py check --chapter $chapter
  
  # 4. 去AI味
  python3 tools/novel-humanizer.py --file chapter-$chapter.md
  
  # 5. 事实更新
  python3 tools/fact-snapshot.py write -c $chapter
  
  # 6. 合同校验
  python3 tools/contract-tree.py check
done

# 晚间汇总（18:00）
python3 tools/wordcount-check.py --report daily
echo "【日报】$(date)" >> projects/my-novel/logs/daily.log
```

### 6.3 问题排查

```bash
# 查看最近问题
cat projects/my-novel/logs/issues.log | tail -20

# 查看系统状态
python3 tools/team-launch.py

# 查看详细日志
tail -50 projects/my-novel/logs/daily.log

# 重新运行失败步骤
python3 tools/gate-check.py check --chapter 1 --retry
```
