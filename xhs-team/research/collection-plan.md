# 小红书 10W+ 爆款文章采集与研究计划

## 目标
- 收集 100+ 篇 10W+ 赞的爆款文章
- 多维度深入分析（选题/标题/结构/情绪/视觉/话题标签等）
- 输出可执行的内容策略

## 数据采集策略

### 关键词组合（按赛道分类）
1. **AI工具评测**：AI评测、AI工具推荐、AI写作、AI绘图
2. **副业赚钱**：副业、AI副业、在家赚钱、搞钱
3. **职场成长**：职场干货、升职加薪、简历优化
4. **生活技巧**：省钱攻略、生活小妙招、收纳整理
5. **美妆护肤**：护肤测评、化妆教程、成分党
6. **美食烹饪**：快手菜、减脂餐、烘焙教程
7. **读书笔记**：书摘分享、读书心得、自我提升
8. **穿搭时尚**：OOTD、穿搭技巧、小个子穿搭
9. **情感关系**：恋爱技巧、婚姻经营、情绪管理
10. **旅行攻略**：小众旅行地、穷游攻略、拍照技巧

### 页面特征识别
- 10W+ 标识位置（通常在点赞数下方或侧边）
- 笔记类型（图文/视频）
- 发布时间范围
- 作者粉丝量级

## 分析维度

### 内容层
- 标题公式（数字型/提问型/反差型/利益型）
- 开头钩子（3秒内抓住注意力）
- 结构模式（总分总/递进式/对比式/清单式）
- 结尾互动（引导评论/收藏/关注的话术）

### 数据层
- 点赞/收藏/评论比例
- 发布时间与流量关系
- 话题标签选择策略
- 封面图类型（真人出镜/产品图/文字卡片）

### 合规层
- AI 使用声明
- 商业推广标注
- 敏感词规避

## 输出格式
每篇文章记录：
```json
{
  "id": "笔记ID",
  "title": "标题",
  "likes": 点赞数,
  "type": "图文/视频",
  "author": "作者名",
  "tags": ["话题标签"],
  "analysis": {
    "title_formula": "标题公式类型",
    "hook_type": "开头钩子类型",
    "structure": "文章结构",
    "cover_type": "封面类型"
  }
}
```
