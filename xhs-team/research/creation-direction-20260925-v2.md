## 三、与团队能力最匹配的方向

### 团队核心能力回顾

| 能力 | 说明 |
|------|------|
| **一手实测** | 有 iSH Linux 环境，可真机跑工具 |

### 推荐方向（按优先级）

#### 🥇 第一推荐：AI 工具实测 + 评测

| 维度 | 评估 |
|------|------|
| **赛道定位** | 科技数码 × AI 工具 = 高增速蓝海（+500%） |
| **搜索关键词** | 「AI 工具推荐」「AI 写作工具对比」「Notion 模板推荐」等 |
| **团队匹配** | 极高（有 iSH 环境可实测，有评测框架） |
| **差异化** | 实测数据 vs 概念介绍（竞品大多没实测） |
| **变现路径** | 模板/工具推荐 + 知识付费 |
| **风险** | 工具迭代快，内容半衰期短（3-7 天） |

**内容形式**：
- 单工具深测（「我用了 X 30 天，真实感受是...」）
- 多工具横评（「5 款 AI 写作工具对比，我选了 2 个」）
- 工作流方案（「AI + Notion 完整工作流」）
- 踩坑记录（「AI 工具最大的 3 个坑」）

#### 🥈 第二推荐：数码/科技产品评测

| 维度 | 评估 |
|------|------|
| **赛道定位** | 科技数码（+500% 增速） |

| **团队匹配** | 高（有实拍能力，有评测框架） |

| **变现路径** | 带货 + 品牌合作 |
| **风险** | 需要实物，成本高 |

#### 🥉 第三推荐：女性副业/效率方法论

| 维度 | 评估 |
|------|------|


## 五、关键判断

### 5.1 为什么推荐 AI 工具评测

| 理由 | 说明 |
|------|------|
| **平台趋势** | 科技数码 +500%，AI 是最大增长点 |
| **搜索流量** | 70% 用户搜索，「AI 工具」类关键词搜索量大 |
| **团队优势** | iSH 可实测，有评测框架（E1-E4），有完整团队 |
| **差异化** | 竞品大多「概念介绍」，我们「真机实测」 |
| **变现路径** | 工具推荐 → 模板 → 课程，链路清晰 |
| **新号友好** | 素人（<1万粉）贡献 62% 爆款，评测类易起量 |

### 5.2 风险与应对

| 风险 | 应对 |
|------|------|
| 工具迭代快（半衰期 3-7 天） | 做「方法论」而非「单工具」，内容可复用 |
| 实测数据需要持续投入 | 建立「工具测试数据库」，复用历史数据 |
| 合规风险（AI 声明） | 按 E1-E4 门禁执行，强制声明 |
| 同质化 | 「缺点优先」+「实测数据」双差异化 |

### 5.3 起号策略

| 阶段 | 时间 | 动作 | 目标 |
|------|------|------|------|
| **冷启动** | 第 1-2 周 | 发布 5-10 篇评测笔记 | 建立内容标签 |
| **起量** | 第 3-4 周 | 聚焦 1-2 个细分赛道 | 粉丝破 100 |
| **变现** | 第 2-3 月 | 接第一单/卖第一个模板 | 验证变现链路 |
| **规模化** | 第 3-6 月 | 建内容矩阵 + 多平台分发 | 粉丝破 1000 |
