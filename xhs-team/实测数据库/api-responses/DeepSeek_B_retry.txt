# 刷短视频刷到想吐，年轻人开始戒了

最近发现一个现象，周围好几个朋友都把抖音、快手卸了。不是那种“我卸载了又装回来”的假戒，是真不刷了。

问他们为啥，答案出奇一致：**刷的时候挺爽，刷完特别空虚，像被掏空了。**

我以前也不信，觉得不就刷个视频嘛，能有多大瘾。直到有次周末，我本来想刷十分钟放松一下，结果一抬头，仨小时没了。那天晚上我躺在床上，脑子里全是各种BGM和变装特效，明明很累，却睡不着。那种感觉，就像吃了一整包辣条，嘴是过瘾了，胃里翻江倒海。

年轻人开始戒短视频，不是因为短视频不好看，恰恰是因为**太好看了**。算法比你自己还懂你，你喜欢猫，它给你推猫；你喜欢吐槽老板，它给你推职场段子；你刚搜过“减肥”，下一秒全是帕梅拉。这种“精准投喂”让人上瘾，但上瘾的代价是——**你的时间成了别人的流量**。

我有个做自媒体的朋友，前段时间闭关做项目，把手机里的短视频软件全删了。他跟我说，删掉之后第一天浑身难受，像戒断反应；但到了第三天，他突然发现自己能完整读一本书了，脑子也能沉下来想事情了。他说：“以前刷视频是‘时间杀手’，现在才反应过来，它是‘注意力绞肉机’。”

还有更现实的例子。我表弟，大四，去年考研，一直说没时间复习。结果有天我瞄了一眼他的手机屏幕使用时间，好家伙，日均5小时刷短视频。那5小时够他背一百个单词，做两套数学题了。他不是没时间，是时间全被短视频“吃”了。

年轻人戒短视频，戒的是什么？戒的是那种**碎片化的、即时的、不需要思考的快乐**。这种快乐来得太快，太廉价，以至于让人上瘾，也让人焦虑。你看别人30秒讲完一本书，觉得自己也懂了；看别人3分钟剪完一部电影，觉得不用看了。但事实上，你什么都没得到，只是被“知识获得感”骗了。

当然，我不是说短视频一无是处。它确实有娱乐价值，也能学到东西。但问题在于，**它太擅长“偷走”你的主动思考了**。你刷到的所有内容都是别人喂给你的，你只是在被动接收，没有任何消化和输出。

最近有个词很火，叫“数字断舍离”。很多年轻人开始刻意减少刷短视频的时间，回归长阅读、回归线下社交、回归真实的生活。他们发现，当手机屏幕暗下来，世界反而亮起来了。

**戒掉短视频，不是拒绝娱乐，而是重新夺回对自己时间和注意力的控制权。**

毕竟，人生不是30秒一划的进度条，有些事值得你花一小时、一天、甚至一辈子去慢慢看。

如果你也感觉被短视频“绑架”了，不妨从今晚开始，把手机放远一点。试试看，你会发现，原来自己一天有那么多时间，可以做点真正喜欢的事。
