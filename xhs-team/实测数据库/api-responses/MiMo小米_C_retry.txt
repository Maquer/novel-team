## 真假话推理

**三人的陈述：**
- 甲：「乙在说谎」
- 乙：「丙在说谎」
- 丙：「甲和乙都在说谎」

**逐一假设（用反证法/穷举法）：**

**假设一：甲说真话**
→ 乙说谎 → 乙说的「丙在说谎」是假话 → 丙说真话
→ 丙说「甲、乙都在说谎」为真 → 要求甲说谎
→ 与「甲说真话」矛盾 ❌

**假设二：乙说真话**
→ 甲说「乙在说谎」是假话 → 甲说谎 ✅
→ 乙说「丙在说谎」为真 → 丙说谎
→ 丙说「甲、乙都在说谎」是假话 → 甲、乙中至少一人说真话
→ 甲确实说谎，乙确实说真话，"都在说谎"为假 ✅
→ 无矛盾，成立 ✔️

**假设三：丙说真话**
→ 「甲、乙都在说谎」为真 → 甲说谎
→ 甲说「乙在说谎」为假 → 乙说真话
→ 与「甲、乙都说谎」矛盾 ❌

## 结论

**乙说的是真话；甲和丙在说谎。**
