我们被问到："甲乙丙三人,甲说乙在说谎,乙说丙在说谎,丙说甲乙都在说谎。谁在说真话?请给出推理过程。"

我们需要确定谁在说真话。三人：甲、乙、丙。他们说的话：
甲：乙在说谎。
乙：丙在说谎。
丙：甲乙都在说谎。

我们需要找出真相。让我们用逻辑推理。

假设我们尝试分配每个人的陈述的真假。

设：
A: 甲说真话或谎话。
B: 乙说真话或谎话。
C: 丙说真话或谎话。

甲说：乙在说谎。所以如果A为真，那么B为假；如果A为假，那么B为真（因为甲在说谎，所以乙不是在说谎，即乙在说真话？注意：甲说“乙在说谎”，如果甲说谎，则“乙在说谎”为假，即乙在说真话。所以：
如果A真 => B假。
如果A假 => B真。

乙说：丙在说谎。所以：
如果B真 => C假。
如果B假 => C真。

丙说：甲乙都在说谎。所以：
如果C真 => A假且B假。
如果C假 => A真或B真？实际上，丙说“甲乙都在说谎”，如果丙说谎，则“甲乙都在说谎”为假，即甲乙并不都在说谎，也就是说至少有一个在说真话。所以：C假 => (A真或B真)或(至少一个真)即A∨B真。更精确：如果丙说谎，则该陈述为假，即并非(甲和乙都在说谎)，所以甲和乙中至少有一个说真话。所以C假意味着A∨B真。

我们需要一致地找到一个赋值。

让我们尝试几种可能性。

方法1：假设丙说真话（C真）。那么根据丙的陈述，A假且B假。所以A假，B假，C真。
然后检查甲的陈述：甲说乙在说谎。因为B假（乙在说谎），所以甲的陈述“乙在说谎”是真的。但甲说假话（因为A假），所以矛盾。因此丙不能说真话。

所以丙说假话（C假）。

那么丙说谎，所以“甲乙都在说谎”为假，即甲乙并不都在说谎。所以至少甲或乙（或者两人）中有一个说真话。即A∨B真。

现在我们有C假。我们需要确定A和B。

乙说：丙在说谎。因为C假，丙确实在说谎，所以乙的陈述“丙在说谎”是真的。所以乙说真话。所以B真。

那么A呢？甲说：乙在说谎。因为B真（乙在说真话），所以乙不在说谎，即甲的陈述“乙在说谎”为假。所以甲说谎。所以A假。

检查：A假，B真，C假。那么A∨B真（因为B真），符合丙的陈述（因为C假，丙说谎的条件是A∨B真，成立）。甲的陈述：乙在说谎，因为B真，所以甲说谎，与A假一致。乙的陈述：丙在说谎，C假，所以乙说真话，与B真一致。丙的陈述：甲乙都在说谎，但A假（甲说谎），B真（乙说真话），所以并非都在说谎，所以丙说谎，一致。

所以一致：甲说谎，乙说真话，丙说谎。

因此，乙在说真话。
