# AI 写小红书笔记，4 款国产模型 1 款直接淘汰：MiniCPM 的 CoT 泄露踩坑实录

⚠️ 利益披露：自费评测，API 免费档+少量调用成本，无品牌合作、无返佣。正文引用的模型输出片段为被评测对象的 API 原始返回，非 AI 辅助写作产物。评分标准与原始输出全部公开可复现。

【结论先说】4 款国产小模型，3 款可用但风格差大，1 款（MiniCPM5-2B）把 chain-of-thought 直接吐进 API 响应，放弃。

【数据来源】2026-09-24 API 实测。测：DeepSeek-V4-Flash / Qwen3.8-Flash-Next / MiMo-V2.6-Flash / MiniCPM5-2B，每款 4 任务（种草 A / 长文 B / 逻辑 C / 润色 D）×1 次。GLM-5.3-Flash 因 API credits 不足 4 任务全失败，未测，不纳入结论。

## 一、评分（4 维度 × 4 任务 = 满分 80）

| 模型 | 准确性 | 自然度 | 完整度 | 实用性 | 总分 |
|---|---|---|---|---|---|
| Qwen 通义 | 18 | 19 | 18 | 16 | **72** |
| MiMo 小米 | 18 | 19 | 18 | 16 | **72** |
| DeepSeek | 17 | 18 | 17 | 16 | **69** |
| MiniCPM 面壁 | 13 | 13 | 14 | 11 | **51** |

均值 66 分。放弃线（测试前预声明）：总分低于均值且任一任务实用性 ≤2 分。MiniCPM 51 分、C 任务实用性 2 分，双重触发。

---

## 二、MiniCPM 为什么直接淘汰（核心发现）

它的 API 原始输出前段就是模型的自言自语，不是提示词泄漏，是 chain-of-thought 原样返回：

> "用户是商家，语气要活泼热情"
> "我需要先确定文章结构"

C 任务（逻辑推理题）输出被截断在推理中，**没有结论**——实用性给 2 分。

同一 prompt 换 DeepSeek / Qwen / MiMo，推理过程全部被抑制，直接返回成品。

API 调用和网页版是两码事：网页版默认隐藏推理，API 通道把它原样吐给调用方。2B 参数档想上生产链路，先确认一句：它把 CoT 也返回吗？

---

## 三、剩下 3 款的风格差（不是高低，是画风）

- **Qwen（72）文艺范** — B 长文出 3777 字，含"朋友真实案例"，语言有质感，像"有生活感悟的文艺青年"
- **MiMo（72）活泼范** — 用"卷王🔥""开车党狂喜🚗"这类网络梗，B 长文带具体数据（日均 4h20min→40min）
- **DeepSeek（69）稳重范** — C任务的推理链清晰，但 B 长文开头多一句"好我按你要求"的废话，发布前要手动删

三款总分只差 3 分，选型依据不是分数，是第五节的场景映射。

---

## 四、全模型共同短板：润色任务 D

4 款 D 任务（原始输入 27-34 字）实用性**全部 ≤ 3 分**。输出被压到 80-102 字之间，"充一次电能用一整天"这类压缩丢细节。想拿来润色，还得自己改回来。通用语言模型对"保留原意"的约束执行不好，属共性问题。

---

## 五、适用建议（按实测场景映射）

> 以下是我自己的使用感受，不同人可能有不同体验，仅供参考。

- 小红书种草 → MiMo / Qwen（我用 MiMo 感觉更活泼）
- 深度长文 → Qwen（真实案例）或 MiMo（具体数据）
- 逻辑推理校验 → MiMo（C 任务三种假设穷举验证，格式清晰）
- 2B 及以下国产小模型，API 调用前先确认它会不会把 CoT 一起返回

⚠️ 本轮结论覆盖 4 款，GLM 未测不纳入。
