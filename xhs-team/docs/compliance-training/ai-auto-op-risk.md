## 关键问题分析

### Q1：xiaohongshu-hub API 发布是否算「AI 自动生成/发布」？

**初步判断**：不算。

**理由**：
1. API 只是传输工具，内容由人工撰写（昭断）+ 人工审核（端绳）
2. 发布前有多层人工 gate（E1-E4 + 昭断 + 端绳）
3. 规则 #19 针对的是「AI 自动运营」，核心是 AI 做决策而非 AI 当管道

**类比**：公众号 API 直推草稿箱不算 AI 自动运营——工具不等于运营者。

### Q2：评论区自动回复是否触发？

**初步判断**：✅ 触发，需下线。

**理由**：
1. 「使用 AI 工具自动回复评论、私信」明确在规则 #19 案例中
2. 目前 xhs-team 暂无自动回复评论功能，暂无风险
3. 如未来加自动回复，必须加「人工确认后发布」环节

### Q3：xiaohongshu-hub 自动发布是否有「批量操作」风险？

**待确认**：
- 单次发布：安全（人工逐篇审核）
- 批量发布（同一 API 批量推多篇）：需评估频率是否触发「批量发布」条款
