# 小红书导流避坑规则

> 来源：小红书官方账号「规则百科薯」2026/7/31 发布  
> 笔记：【新规速递】避开这些导流动作，流量更稳（5.8 万赞 / 10 万+ 阅读）  
> 归档日期：2026-09-24

---

## 一、三种高风险场景（来自用户反馈）

| 场景 | 典型问题 | 后果 |
|------|---------|------|
| 学习类博主 | 考研资料出掉 → 加联系方式 | 流量悄悄变低 |
| 知识分享类博主 | APP 教学笔记 → 流量不好 | 被系统限流 |
| 商业财经类博主 | 简介写"地球号领资料" → 被限流 | 账号限流 |

---

## 二、三条红线（官方判定）

### 红线 1：留联系方式

| 情况 | 是否允许 | 备注 |
|------|---------|------|
| 个人出闲置 / 转租 / 找搭子 | ✅ 可 | 正常沟通没问题 |
| 商家长期待卖货 | ❌ 必须走站内 | 建议走店铺 / 企业号 / 买手认证 |
| 笔记正文 / 评论 / 私信引导加微信 | ❌ 高概率限流 | 无论是否商业目的 |

### 红线 2：提到其他平台

| 情况 | 是否允许 | 备注 |
|------|---------|------|
| 客观提到平台名字 | ✅ 可 | "我用过 XX App" |
| 高频引导去其他平台交易 / 下载 / 关注 | ❌ 限流 | "去某宝搜 XX"类 |
| 简介中埋暗号引导站外 | ❌ 高风险 | 见红线 3 |

### 红线 3：变体暗号

| 示例 | 风险等级 | 说明 |
|------|---------|------|
| "地球号" | 🔴 高 | 被系统识别为导流动作 |
| "薇❤️" | 🔴 高 | 谐音变体反而易被识别 |
| "看简介数字" | 🔴 高 | 暗示读者看图/简介 |
| 任何变体 / 暗号 / 省略 / 打码形式 | 🔴 高 | 官方明确：反而更容易被系统识别 |

---

## 三、官方顺口溜（背下来）

> **个人交流可放心，商家卖货走站内；**  
> **客观提及没关系，高频导流会限流；**  
> **变体暗号不要碰，真诚表达最长久。**

## 五、FAQ

**Q：客观介绍竞品算导流吗？**  
A：不算。"XX App 也有类似功能"是客观陈述，不构成引导。

**Q：评论区回复"私聊"算违规吗？**  
A：算。即使非商业目的，系统也会识别为导流动作。

**Q：简介写"联系方式看主页"可以吗？**  
A：不可以。属于暗示性引导，已被官方明确列为高风险。

**Q：企业号 / 店铺可以留联系方式吗？**  
A：可以。走站内店铺 / 企业号通道是合规方式。
