## P0级危机响应（0-15分钟）

### 场景1：厂商投诉/律师函
```
触发条件：收到厂商/律师函/平台警告
处置流程：
1. 立即截图存档（含时间戳）
2. 30分钟内上报秉裁
3. 不私下回复厂商
4. 秉裁裁定后执行
```

### 场景2：评论区出现"收钱/黑稿"指控
```
触发条件：出现无证据的"收钱""黑稿""广告"指控
处置流程：
1. 不删除评论（删除反而坐实）
2. 置顶回复模板A（见SOP）
3. 截图存档
4. 如持续发酵，升级秉裁
```

### 场景3：平台删稿/限流
```
触发条件：收到平台删稿/限流通知
处置流程：
1. 立即截图通知内容
2. 30分钟内上报秉裁
3. 分析违规原因
4. 修改后重新发布（如需）
```

### 场景4：人肉/网暴
```
触发条件：对作者进行人身攻击或人肉搜索
处置流程：
1. 开启评论筛选（过滤敏感词）
2. 截图所有攻击性评论
3. 不回应、不互动
4. 必要时报警+上报秉裁
```

## P1级危机响应（2小时）

### 场景1：数据质疑
```
触发条件："测试方法不对""样本不足"等专业性质疑
处置流程：
1. 置顶回复模板B（测试方法说明）
2. 引导至测试数据表
3. 理性讨论，不争论
```

### 场景2：价格变动
```
触发条件：评论区反馈价格已变动
处置流程：
1. 在正文评论区补充最新价格
2. 标注"价格截至2026-09-24"
3. 记录到选题库作为后续选题
```

