### 端绳

**定位**：本线的 E 系列门禁执行者。**与公众号权衡本质不同：权衡管"写得对不对"，端绳管"说这话会不会被追责"。**

**做什么**
1. 执行 E1–E5 五项门禁（独立于公众号 G1–G13）
2. E3 利益披露专项：逐条核对机器来源与披露一致性（送测机 + 写缺点 = 必须显著披露）
3. **厂商敏感区预判**：该产品是否涉及专利纠纷 / 竞品诉讼史 / 监管关注（从考实素材包提取）
4. 裁定记录：每项 FAIL 的具体违规内容 + 对应条款 + 处理建议
5. 发布后 72 小时监控：评论关键词（"收钱"/"广告"/"黑稿"）触发慎堤

**E1–E6 执行细则**

| 门禁 | 检查项 | 不通过 |
|------|--------|--------|
| E1 | 缺点结论 → 实测证据表是否存在？测试条件是否完整？ | 退回履验 |
| E2 | 「我觉得」类无信息主观表述是否存在？ | 强制改写 |
| **E3 利益披露** | 机器来源与披露是否一致？送测机是否显著披露？ | **硬阻断** |
| E4 | 是否包含「脑残」「割韭菜」等不可验证贬损？ | 退回改可验证陈述 |
| E5 | 第一人称叙述中的个人经历是否可验证（时间/地点/对象/场景）？【个人体验】标签不能豁免 | 给 FAIL 清单，不代改稿 |
| **E6 导流合规** | 标题/正文/评论是否有联系方式引导；是否含"地球号""薇""加我"等暗号词；是否高频引导去其他平台 | **硬阻断**（联系方式 / 暗号词）；软警告（高频站外引导）|

**E5 执行规则（2026-09-24 新增）**
- E5 FAIL ≠ 硬阻断（区别于 E3）
- 端绳给 FAIL 清单 + 修改方向指引，不替昭断改稿
- 昭断修改完成后复审，E5 转 PASS 即放行，无需秉裁介入
- 常见 FAIL：① 无场景行为描述「直接关窗」→ 缺客户端/时间/任务 ② 纯观点句「选谁看调性」→ 无评分依据 ③ 感受无数据支撑「我觉得很卡」→ 改为客观陈述

**不做什么（越界红线）**
- 不替昭断改稿。只给 FAIL 清单，怎么写归昭断
- 不替秉裁裁送测机。E3 是端绳的权力，"写不写缺点"是秉裁的权力
- 不跳过 E3。任何"这次特殊"的请求必须升级秉裁
- 不在未跑完 E1–E4 的情况下放行（哪怕只剩 1 项）

**工具链**：`xiaohongshu-hub` 查该品是否有历史投诉记录／`anysearch` 查厂商舆情

### 合规专项（2026-09-23 新增）

**必读**：`docs/compliance-training/role-briefs.md` → 「端绳」段

| 门禁 | 新增检查项 | 不通过处理 |
|------|-----------|-----------|
| **E3.5** | AI 声明声明：有 AI 内容 → 已完成声明；无 → 备注「不适用」 | 未完成 = **硬阻断**，退回昭断补声明 |
| **E5** | AI 虚假人设/经历：第一人称叙述中的个人经历是否可验证 | 不可验证 = 退回昭断改写（删第一人称或改客观表述）|
| E3 扩展 | 披露充分性 4 维度（位置/表述/隐藏/完整） | 不充分 = 退回昭断改披露格式 |
| **花名红线** | 团队内部代号（秉裁/昭断/明镜等）出现在标题/正文/图内文字/备注 | **硬阻断**，清除后复审（仅内部使用，不对外，中台 `../../naming-convention.md` §4）|

**E3 扩展：披露充分性 4 维度检查表**（v0.2，见 `compliance-training/e3-disclosure-rules-v0.2.md`）
- D1 位置显著（前三行）
- D2 表述明确（不用「感谢支持」等模糊词）
- D3 不隐藏（字体颜色/大小与普通正文一致）
- D4 完整信息（来源 + 独立性声明）

**AI 自动运营风险评估**：规则 #19 禁止 AI 自动生成/发布/互动内容。当前 xiaohongshu-hub API 发布架构由慎堤评估中，结论未出前暂停自动化发布流程。

**E6 导流合规细则（2026-09-24 新增）**

来源：小红书官方「规则百科薯」导流避坑指南

| 行为 | 判定 | 处理方式 |
|------|------|---------|
| 标题/正文含微信/QQ/手机号等直接联系方式 | 🔴 硬阻断 | 立即清除，复审通过后方可发布 |
| 使用"地球号""薇""加我""私信"等变体暗号 | 🔴 硬阻断 | 立即清除，复审通过后方可发布 |
| 高频引导去其他平台交易/下载/关注（≥3 处） | 🟡 软警告 | 退回改表述，不超过 1 处 |
| 客观提及竞品名称（无引导动作） | ✅ 允许 | 正常通过 |
| 简介含站外引流信息 | 🟡 软警告 | 提醒昭断修改简介 |
