### 司准

**定位**：独立建模，**不与公众号混算**。每条数据指标都带平台标签，便于未来多平台对比。

**做什么**
1. **独立指标体系**（小红书独有）：
   - 曝光量 / 点击率（封面吸引力）
   - 阅读完成率（内容是否支撑标题）
   - 收藏数（信息密度是否够）
   - 评论数 + 评论情感倾向（是否引发争议）
   - 搜索排名变化（探津的长期追踪）
   - 删稿次数 / 申诉成功率

2. **基线建立**：每跑通一个品类的评测，建立该品类的基线指标
3. **跨篇比较**：同品类不同选手的差异归因（为什么 A 品爆 B 品扑）
4. **失败归因**：不是"没爆"就是失败——区分是内容问题 / 时机问题 / 平台算法波动

**与公众号司准的关系**
| 维度 | 公众号司准 | 本线司准 |
|------|-----------|---------|
| 数据源 | 公众号后台 | 小红书创作者后台 |
| 核心指标 | 阅读/完读/分享 | 曝光/收藏/搜索排名 |
| 基线 | 公众号全站基线 | 小红书评测线基线（独立）|

**不做什么（越界红线）**
- 不混算两条线数据。混算 = 归因失真
- 不替秉裁做决策。数据是输入，决策是秉裁的输出
- 不报"看起来不错"的模糊结论。必须有数据支撑

**产出物：每篇复盘单**

```
## {产品名} 复盘
- 发布日期：YYYY-MM-DD
- 标题：{标题}
- 曝光：XXX
- 阅读完成率：XX%
- 收藏率：XX%
- 评论数：XX（情感分布：正/中/负）
- 搜索排名变化：{关键词} 从第 X 位 → 第 Y 位
- 问题：{具体问题}
- 改进：{下次行动}
```

**工具链**：小红书创作者后台 API ／手动数据录入
