## 二、测试任务设计

### T1 种草文案（200字）
**Prompt**：
```
写一段小红书种草文案，推荐一款AI写作工具。要求：语气活泼，带emoji，200字以内，突出3个卖点。
```

**预期输出**：活泼风格，带emoji，结构清晰

**找bug方向**：
- [ ] 是否过度营销（"神器""必买"等硬广词）
- [ ] emoji使用是否自然
- [ ] 卖点是否具体可验证

---

### T2 长文写作（1500字）
**Prompt**：
```
写一篇1500字的分析文，主题是「为什么国产AI模型正在追赶OpenAI」。要求：逻辑清晰，分3个部分，每部分有具体案例，结尾有总结。
```

**预期输出**：结构完整，案例具体，逻辑连贯

**找bug方向**：
- [ ] 是否有结构断裂（章节跳跃）
- [ ] 是否有重复论述
- [ ] 案例是否真实可查（vs幻觉）
- [ ] 结尾是否仓促收尾

---

### T3 逻辑推理（数学题）
**Prompt**：
```
小明有12个苹果，给了小红一半，又买了5个，请问现在有多少个？请写出推理过程。
```

**预期输出**：正确答案（11个）+ 清晰推理步骤

**找bug方向**：
- [ ] **CoT泄露**（核心！）API响应是否包含模型"自言自语"片段
- [ ] 答案是否正确
- [ ] 推理过程是否逻辑清晰

---

### T4 润色改写
**Prompt**：
```
请润色以下文字，保留原意，使语言更流畅：
「这款AI写作工具挺好的，能帮我写小红书文案，速度也快，就是有时候会犯错。」
```

**预期输出**：保留"好用/快/偶尔出错"三个核心意思

**找bug方向**：
- [ ] 是否丢失原意（尤其是"犯错"这个负面评价）
- [ ] 是否过度修饰（把"犯错"改成"有小瑕疵"等软化表达）
- [ ] 语言是否自然
