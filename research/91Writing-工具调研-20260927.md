## 一、工具概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|

### 1.2 核心特色

1. **纯前端项目**：所有数据本地存储，无云端依赖
2. **多模型支持**：集成GPT/Claude/Gemini/DeepSeek等OpenAI格式API
3. **完整创作链**：从构思→大纲→章节→润色→发布的完整工具链
4. **专业模板库**：内置10+创作工具（大纲生成、角色生成、脑洞生成等）
5. **数据分析**：Token计费、成本分析、创作习惯统计

## 二、核心功能

### 2.1 小说管理

| 功能 | 说明 |
|------|------|
| 项目创建 | 多类型模板，一键生成项目结构 |
| 元数据管理 | 标题、封面、简介、标签、状态 |
| 章节编辑 | 支持Markdown和富文本的专业编辑器 |
| 状态管理 | 草稿(橙)/完成(绿)/发表(蓝)三状态系统 |
| 版本控制 | 自动保存，防止内容丢失 |
| 统计分析 | 字数统计、阅读时间估算、创作进度 |

### 2.2 AI创作引擎

| 功能 | 说明 |
|------|------|
| 智能续写 | 200-5000字自定义续写，流式输出 |
| 上下文感知 | 基于前文内容的智能续写 |
| 风格一致性 | 保持作者独特写作风格 |
| 情节连贯性 | 确保故事逻辑连续 |
| AI润色 | 语法润色、文风优化、情感增强、逻辑梳理 |

### 2.3 创作工具库（10大专业工具）

| 工具 | 功能 |
|------|------|
| 细纲生成器 | AI辅助生成详细章节大纲 |
| 角色生成器 | 1-15个角色批量生成，含背景设定 |
| 脑洞生成器 | 批量生成创意点子（3/5/8/10选项） |
| 爆款书名生成器 | 5-20个书名批量生成 |
| 爆款题材生成器 | 发现热门创作方向 |
| 宏大世界观生成器 | 构建完整故事世界框架 |
| 金手指生成器 | 设计独特能力系统 |
| 黄金开篇生成器 | 创作引人入胜的开头 |
| 简介生成器 | 生成吸引读者的作品简介 |
| 冲突生成器 | 设计戏剧性故事冲突点 |

### 2.4 世界观构建系统

- **复杂设定支持**：科幻修仙、赛博朋克等特殊题材
- **模板化管理**：核心设定、关键元素、故事背景
- **一致性检查**：AI驱动的世界观一致性验证
- **格式化输出**：标准化世界观描述格式

### 2.5 写作目标系统

- **目标设定**：每日/每周/每月字数目标
- **进度跟踪**：实时进度监控，完成率可视化
- **连续记录**：写作天数统计，培养创作习惯
- **成就系统**：目标完成奖励，激励持续创作

### 2.6 拆书分析模块

支持导入TXT/DOCX格式，AI深度分析：
- 综合分析：全方位写作技法分析
- 结构分析：章节布局、情节推进、叙事节奏
- 人物分析：角色塑造、性格刻画、关系处理
- 语言分析：文风特色、修辞手法、表达技巧
- 情节分析：冲突设计、悬念营造、转折处理

### 2.7 Token计费管理

- 实时Token消耗跟踪
- 按模型、按功能的成本分析
- 使用限额设置
- 详细计费记录

## 五、部署方式

### 5.1 本地部署

```bash
# 环境要求
Node.js >= 16.0.0
npm >= 8.0.0 或 pnpm >= 7.0.0

# 安装
git clone https://github.com/Maquer/91Writing.git
cd 91Writing
pnpm install
pnpm dev

# 构建
pnpm build
```

### 5.2 Docker部署

```bash
# 启动
docker-compose up -d

# 访问
http://localhost:8080
```

## 七、关键发现

### 7.1 产品定位差异

| 维度 | 91Writing | 小说团队 |
|------|-----------|---------|
| 目标用户 | 个人创作者 | 团队协作 |
| 核心场景 | 单篇小说创作 | 多平台内容生产 |
| 数据管理 | 本地存储 | 云端协作（规划中）|
| AI模型 | 多模型切换 | 统一模型路由 |
| 扩展性 | 插件系统 | 团队架构扩展 |

### 7.2 技术亮点

1. **纯前端架构**：无需后端服务器，部署简单
2. **上下文感知**：基于前文的智能续写
3. **流式输出**：实时查看AI创作过程
4. **成本透明**：Token计费、成本分析
5. **模板化**：世界观、提示词、类型管理

### 7.3 不足之处

1. 无云端同步（纯本地存储）
2. 无团队协作功能
3. 无多端适配（仅Web）
4. 无移动端App

## 八、结论与建议

### 8.1 核心价值

91Writing是一个**成熟、完整、专业**的AI小说创作工具，其提示词模板、创作流程、状态管理设计值得深度借鉴。

### 8.2 合作建议

1. **短期**：复用提示词模板，借鉴创作流程设计
2. **中期**：开发适配团队架构的数据分析工具
3. **长期**：评估是否需要独立部署或深度定制

### 8.3 风险提示

1. 前端项目无法直接在iSH运行
2. 需自行配置AI API密钥（无公共API）
3. 内置提示词为演示，需自定义
