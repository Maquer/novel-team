## 一、工具概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 名称 | 51mazi（我要码字）|
| 定位 | 桌面端小说写作软件 |
| 技术栈 | Electron + Vue 3 + TipTap |
| Stars | 471 ⭐ |
| License | MIT |

### 1.2 核心特色

1. **AI辅助创作**：AI生成封面、人物图、场景图
2. **专业写作体验**：富文本编辑器、实时统计、禁词提示
3. **创作辅助工具**：地图设计、关系图谱、时间线、组织架构
4. **多书籍管理**：书架式管理、密码保护
5. **下载小说**：支持网文下载

## 二、核心功能

### 2.1 AI生成能力

| 功能 | 说明 |
|------|------|
| AI生成封面 | 通义万相API，按书名/笔名/风格生成 |
| AI生成人物图 | 支持多种画风（日系/吉卜力/写实） |
| AI场景图 | 选中正文→生成场景插图 |
| AI润色 | 一键润色选中文本或整章 |
| AI续写 | 输入续写要求，AI生成续写结果 |

### 2.2 创作辅助工具

| 工具 | 功能 |
|------|------|
| 地图设计 | Canvas绘图，支持画笔/橡皮/形状/文字/资源 |
| 关系图谱 | 可视化人物关系网络 |
| 人物档案 | 完整角色管理 |
| 时间线 | 事件时间轴管理 |
| 事序图 | 剧情顺序管理 |
| 组织架构 | 势力/门派管理 |
| 词条字典 | 词汇管理体系 |
| 随机取名 | 角色命名生成 |

### 2.3 写作体验

- 富文本编辑（TipTap）
- 实时字数统计
- 码字速度显示
- 自动保存
- 全文搜索
- 快捷键支持
- 多主题（亮色/暗色/护眼）
- 人物高亮
- 禁词提示
- 段落拖拽

## 四、关键发现

### 4.1 AI辅助创作的实用化

51mazi的核心价值在于把AI能力**实用化**：
- 不是泛泛的"AI写作"，而是具体的封面/人物/场景生成
- 每次生成都有明确的目的和输出格式

### 4.2 创作辅助工具的完整性

从大纲到正文到发布，提供了完整辅助工具链：
- 地图设计（世界观可视化）
- 关系图谱（人物管理）
- 时间线（事件追踪）
- 组织架构（势力管理）

### 4.3 写作体验的细节

- 禁词提示：实时检测并标记
- 人物高亮：方便追踪角色出场
- 码字速度：激励连续写作

## 五、结论与建议

### 5.1 核心价值

51mazi是一个**功能完整、界面友好**的桌面写作软件。其核心价值在于：
- 把AI能力融入创作流程（而非独立功能）
- 提供了丰富的创作辅助工具
- 注重写作体验的细节

### 5.2 与小说团队的关系

| 维度 | 评估 |
|------|------|
| **可运行** | ❌ Electron应用，iSH无法直接运行 |
| **可借鉴** | ✅ 部分可借鉴（禁词、图谱、时间线）|
| **可复用** | ⚠️ 部分可复用（数据模型、AI调用逻辑）|

### 5.3 推荐集成路径

1. **短期**：扩展禁词系统、增强关系图谱
2. **中期**：开发时间线管理工具
3. **长期**：评估完整部署方案
