### 1.2 核心特色

1. **指纹蒸馏机制**：5篇同类型源文→提取公约数→剔除作者指纹→生成100%原创内容
2. **12阶段创作管道**：脑洞→灵感风暴→人设→大纲→细纲→概要→开篇→正文→优化→润色→续写→扩写
3. **链式传递**：分阶段输出可传递给下一阶段，实现真正的流水线创作
4. **后处理工具**：脏逗号清理 + 标点密度注入（模拟番茄风格）
5. **质量审计**：9项爆款规则检测 + 独创度审计（朱雀扫描）

## 三、核心创新

### 3.1 指纹蒸馏机制（最关键创新）

```
5篇源文 → 提取结构化指纹 → 对比提取公约数 → 剔除作者指纹 → 输出LLM可用上下文
```

**指纹字段**：
- 字数、句数
- `!/句`（感叹号密度）、`,/句`（逗号密度）
- 是否使用引号
- 开篇30行（前缀样本）
- 高频人名（jieba分词）

**公约数 vs 作者指纹**：
| 维度 | 公约数（保留） | 作者指纹（剔除） |
|------|---------------|-----------------|
| 死亡方式 | 从5篇中最少出现的选一个全新 | 高频死亡方式 |
| 重生触发 | 公约数保留 | 5篇都用"车祸"则自创 |
| 背景设定 | 挑一个5篇都不用的全新设定 | 常见设定 |
| 背叛者 | 公约数保留 | 特定人物关系 |
| 复仇手段 | 从5篇都不用的方法中自创 | 常见手段 |
| 独特道具 | 剔除，自创全新 | 特定道具 |

**目标**：朱雀对着5篇源文扫描输出的16字连续子串，一个都匹配不到。

### 3.2 硬性约束系统

```python
# 禁用句式（朱雀扫描易匹配）
BANNED_PATTERNS = [
    "对X而言", "一切都在", "她心想", "她意识到", "她感到",
    "一种说不出的", "真正的X是Y", "X的意义在于", "X既是Y也是Z",
    "谁说X就一定Y",
]

# 禁用模板描写
BANNED_TEMPLATES = [
    "眼中闪过", "嘴角勾起", "眼眶微红", "不可置信",
    "眼底闪过", "咬了咬唇", "冷冷地说"
]

# 风格规则
HARD_RULES = """
- 第一人称
- 数字分节: 1 2 3...(裸数字，无标题)
- 分隔符: ……
- 精确数字: 金额/时间/数量精确到个位
- 压缩情感循环: 每弧≤8句
- 短段快节奏: 一段=一个动作/一句对话/一个念头
- 番茄小白话: 小学六年级词汇为主,复句≤30%
- 零思维标记: 禁用 心想/意识到/感到/觉得/认为
- 人设标签(≥3): 杀伐果断/清醒独立/拒绝内耗/黑莲花/人间清醒/搞钱脑
"""
```

### 3.3 12阶段创作管道

| 序号 | 阶段 | 说明 | 对应提示词 |
|------|------|------|------------|
| 1 | 脑洞 | 创意构思/卖点/受众定位 | `prompt_inspiration.md` |
| 2 | 灵感风暴 | 书名/简介/黄金开局大纲/角色小传 | `prompt_inspiration.md` |
| 3 | 人设 | 角色设计/金手指/关系网 | `prompt_character.md` |
| 4 | 大纲 | 故事主线/情节点/高潮 | `prompt_outline.md` |
| 5 | 细纲 | 章节拆分/场次细化 | `prompt_outline.md` |
| 6 | 概要 | 200字高度浓缩梗概 | `prompt_outline.md` |
| 7 | 开篇 | 黄金三章/三句法开头 | `prompt_opening.md` |
| 8 | 正文 | 对话密度/节奏/叙事感 | `prompt_writing.md` |
| 9 | 优化 | 角色归一化/拼接率质检 | `prompt_polish.md` |
| 10 | 润色 | 句式变化/用词多样性 | `prompt_polish.md` |
| 11 | 续写 | 情节延伸/伏笔展开 | `prompt_expand.md` |
| 12 | 扩写 | 细节铺陈/环境描写 | `prompt_expand.md` |

### 3.4 链式传递机制

```bash
# 阶段间通过 -P 参数传递上下文
python run_pipeline.py -s 脑洞 -c 05_古代言情
python run_pipeline.py -s 人设 -c 05_古代言情 -P output/脑洞_output.txt
python run_pipeline.py -s 大纲 -c 05_古代言情 -P output/人设_output.txt
# ...以此类推
```

管道自动推断：若 `output/` 目录下存在 `{前阶段}_output.txt`，无需手动指定 `-P`。

### 3.5 后处理工具

| 工具 | 功能 | 关键参数 |
|------|------|---------|
| `clean_commas.py` | 清理脏逗号（jieba分词去除语法错误逗号） | - |
| `inject_punctuation.py` | 注入标点密度（模拟番茄风格） | `--excl 0.15`（感叹号密度）、`--comma 1.2`（逗号密度） |

## 六、关键发现

### 6.1 为什么朱雀检测不到？

> "5篇不同作者的指纹在交集运算中互消。剩下的'睁眼/背叛/复仇'不属于任何单一作者，属于类型本身。朱雀对输出做16字扫描 vs 全部5篇源文 → 0匹配。"

### 6.2 硬性约束设计的精妙之处

1. **标点禁令**：禁用 `；` `！！！` `？！` `「」`，降低朱雀匹配概率
2. **禁用引号**：对话用 `名字：` 或裸嵌入，而非标准引号
3. **零思维标记**：禁用 `心想/意识到/感到/觉得/认为`，强制外部描写
4. **句式突变**：相邻3句不同结构，打破AI句式规律

### 6.3 链式传递的实用性

- 支持 `--previous-output` / `-P` 参数
- 管道自动推断前序阶段输出
- 每次运行重新扫描语料，但保持上下文连续性
