## 一、工具概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 名称 | MaliangAINovalWriter（马良AI写作）|
| 定位 | AI小说创作平台（网文）|

### 1.2 核心特色

1. **多智能体AI创作**：三级大纲（作品→卷→章节→场景）
2. **知识图谱一致性**：角色、剧情线、伏笔跨章节一致性
3. **世界观构建**：AI生成结构化设定树，支持增量修改与历史快照
4. **剧情推演**：多模型抽卡机制，生成多个后续剧情选项
5. **知识库拆书**：AI分析优秀小说，提取创作知识
6. **LLM可观测性**：详细记录每次AI调用，提供日志查询和成本追踪

## 二、核心架构

### 2.1 四级内容结构

```
作品 → 卷 → 章节 → 场景
```

### 2.2 核心功能模块

| 模块 | 功能 |
|------|------|
| **核心写作** | 富文本编辑器、大纲总览、多级目录、多格式导入 |
| **智能AI助手** | 续写/扩写/润色/翻译、剧情推演、摘要生成 |
| **世界观构建** | 结构化设定、关系网络、AI一键生成设定树、历史快照 |
| **写作分析** | 作者仪表盘、Token消耗趋势、功能使用分布 |
| **提示词管理** | 系统预设、个人预设、预设管理 |
| **管理员后台** | 用户管理、RBAC权限、公共模型管理、LLM可观测性 |

### 2.3 剧情推演（Next Outline）

**多模型抽卡机制**：
- 同时调用多个不同AI模型生成剧情方案
- 对比不同模型的创意输出
- 类似"抽卡"方式选择最合适方案

**上下文智能分析**：
- 自动分析当前章节内容、角色关系、世界观设定、已有大纲
- 生成与故事逻辑高度一致的剧情推演

**分支剧情生成**：
- 每次推演生成多个不同走向的剧情分支
- 帮助作者探索不同叙事可能性

### 2.4 AI拆书与知识库

**多维度知识提取**：
- 文风叙事：叙事方式、文风特点、用词习惯
- 情节设计：核心冲突、悬念设计、故事节奏
- 人物塑造：角色塑造技巧与性格刻画
- 小说特点：世界观构建、金手指系统、力量体系
- 读者情绪：共鸣点、爽点布局、嗨点设计
- 热梗搞笑：流行梗、搞笑点、网络文化元素
- 章节大纲：章节结构与情节发展脉络

**番茄小说直连拆书**：
- 提供小说URL即可自动抓取全文并进行AI分析
- 快速构建专属知识库

## 六、关键发现

### 6.1 多智能体协作模式

MaliangAINovalWriter采用多智能体协作：
- 每个智能体负责不同任务（大纲、角色、世界观、剧情推演）
- 智能体间通过共享知识图谱协调
- 多模型抽卡机制选择最优方案

### 6.2 知识图谱一致性

核心创新是**知识图谱一致性**：
- 角色、地点、势力、物品等实体统一管理
- 实体间的关系有向图
- 跨章节的一致性检查
- 冲突检测和自动修复

### 6.3 剧情推演的多模型抽卡

区别于单一模型生成，采用**多模型抽卡**：
- 同时调用多个AI模型
- 对比不同模型的创意输出
- 选择最合适的剧情走向
- 支持独立重生成不满意选项

### 6.4 AI拆书知识库

创新的**AI拆书**功能：
- 深度分析优秀小说
- 提取多维度创作知识
- 构建专属知识库
- 支持番茄小说直连拆书
