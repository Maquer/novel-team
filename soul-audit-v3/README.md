# soul-audit-v3 — SOUL.md 第三轮自我认知审计

> 时间：2026-09-09 | 方式：4 维多模型交叉审计，含运行证据包

## 文件说明

### `build-v3.py`
**用途**：执行 SOUL.md 的 8 处外科手术修改（v3 版）。

从 `minis-config` 读取当前 SOUL.md，按预定义的规则列表 `R` 做精确字符串替换。每条规则包含 `(旧文本, 新文本)`，要求旧文本在原文中恰好出现 1 次（count=1），否则中止并报告失败位置。修改后输出到 `soul-v3.md` 并写入 `/tmp/soul-v3.json`。

修改覆盖 5 个维度：
- **L（语言修复）**：时间单位统一（≤60min→分钟）、批准范围措辞调整、迭代规则措辞
- **E（错误处理扩容）**：新增空输出/耗时异常处理规则、脚本复用黄金测试、模型调用链限制、静默降级禁止、可用性验证有效期
- **E（停滞提醒）**：从"主动提醒"改为"会话开始扫描注入记忆"的被动可检测形式
- **C+E（状态与恢复）**：新增长任务落盘规则、中断恢复话术、待晋升教训标记、规则书写范式（触发载体自检）
- **C（记忆写入）**：新增"同一知识只写一层"防重复规则
- **规则下推**：将技能命名规范从 SOUL 移除（已落 GLOBAL §三）

### `trim-v3b.py`
**用途**：将 `soul-v3.md` 进一步压缩到 2000 token 上限内（CJK 字符 1 字 = 1 token）。

对 `soul-v3.md` 做等义压缩，每条规则同样要求 count=1 精确匹配。压缩策略：
- **语句压缩**：9 条长句压缩为短句（如"模型调用链上限3个模型×2次"→"3模型×2次"）
- **存量低价值压缩**：删除无载体元规则、简化话术、修正歧义表述（如"≤3 个无关联话题"→"多个无关联话题混杂"）

输出覆盖 `soul-v3.md`，并打印 token 估算（CJK 计数 + 拉丁分词粗估）。

### `soul-v3.md`
**用途**：v3 修改 + v3b 压缩后的最终 SOUL.md 副本（供审核/回滚）。

### `report.md`
**用途**：第三轮自我认知审计报告，含 4 维评分和证据链。

### `raw-202609092250.json` / `rerun-SL.json`
**用途**：审计原始数据（多模型交叉验证的原始输出）。

## 工作流

```
当前 SOUL.md
    → build-v3.py（8 处外科手术修改）
        → soul-v3.md
            → trim-v3b.py（token 压缩）
                → soul-v3.md（最终版，≤2000 token）
```

审核通过后，将 `soul-v3.md` 写回 `minis-config soul.body`。
