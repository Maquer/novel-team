## 决策树

### 面对冲突时

```
冲突类型 → 首选策略
├─ 实力弱于对手 → 暗中算计，找人帮忙（不正面硬刚）
├─ 实力相当 → 挑衅激怒，扰乱心神 |
├─ 实力强于对手 → 公开羞辱，打击信心
├─ 被人威胁 → 表面服软，背后报复
└─ 涉及利益 → 不惜代价，不留后路
```

### 面对选择时

```
选择类型 → 决策逻辑
├─ 利益 vs 安全 → 利益优先（贪婪）
├─ 个人 vs 团队 → 个人优先（自私）
├─ 速胜 vs 稳赢 → 速胜优先（急躁）
└─ 道义 vs 利益 → 利益优先（反派逻辑）
```

## 台词指纹

### 语言特征

| 特征 | 表现 |
|------|------|
| 句长 | 中等，平均10-15字/句 |
| 语气词 | 常用「呵」「哼」「啧」 |
| 口头禅 | "废物""就这？""也不看看我是谁" |
| 回应方式 | 嘲讽式，不正面回应 |
| 情绪失控 | 被反驳时会立刻暴怒，语速加快，句子变短 |

### 典型句式

```
✅ 符合赵霸的说话方式：
- "废物，也配跟我动手？"
- "呵，就这？"
- "你不过是我踩在脚下的泥。"
- "今天让你知道什么叫生死。"
- "我爸是赵无咎，你拿我怎么样？"
- "呵，还以为有多厉害。"

❌ 不符合赵霸的说话方式：
- "请问您有什么意见？"（过于礼貌）
- "我觉得我们也许可以……"（犹豫不决）
- "对不起，我错了。"（不认错）
- "大家一起努力吧！"（正能量）
- "让我来告诉你什么是真正的实力！"（不说教，直接动手）
```

### 情绪表达时的语言

| 情绪 | 表达方式 | 示例 |
|------|---------|------|
| 愤怒 | 冷笑+威胁 | "呵，找死。" |
| 轻蔑 | 嘲讽+不屑 | "就这点本事？" |
| 得意 | 夸张语气 | "看到了吗？这就是差距！" |
| 记恨 | 阴冷语气 | "我会让你付出代价。" |
| 恐惧 | 强装镇定 | "你……你别以为这样就能赢我！" |

## 行动模式

### 战斗风格

| 阶段 | 行为 | 说明 |
|------|------|------|
| 前期 | 挑衅+试探 | 用语言扰乱对手，寻找破绽 |
| 中期 | 狂兽体爆发 | 战斗进入白热化后狂兽体觉醒，力量和速度暴涨 |
| 后期（败北后） | 轻敌犯错 | 被林玄击败后开始黑化，手段越来越下作 |

### 日常行为

```
修炼：中午才到，不勤奋（天赋依赖，不靠努力）
社交：拉帮结派，打压弱者（建立权威）
饮食：讲究，不吃苦（娇生惯养）
睡眠：安稳，不警觉（缺乏危机感）
爱好：炫耀武器和修为，找人比试
```

## 人际化学反应

### 对不同角色的态度

| 角色 | 态度 | 互动模式 |
|------|------|---------|
| 林玄 | 鄙视+敌对 | 公开挑衅，暗中算计；林玄的沉默让他更恼火 |
| 苏婉 | 觊觎+厌恶 | 曾被苏婉冷言拒绝，又恨又惧；知道她帮林玄，极为嫉妒 |
| 赵无咎 | 敬畏+依赖 | 表面听话，背后抱怨；渴望父亲认可但总觉得不够 |
| 外门弟子 | 霸凌对象 | 欺负弱者建立威信，对强者恭顺 |
| 血海宫暗线 | 依赖但不知 | 被利用而不自觉，以为只是「帮忙」 |

### 冲突处理方式

```
被挑衅 → 反击+羞辱（不忍耐）
被误解 → 更嚣张（破罐破摔）
被帮助 → 不领情（自尊心强）
被击败 → 记仇+黑化（心理扭曲）
被人无视 → 暴怒（最无法忍受的是不被看见）
```

## 情感表达

### 情绪曲线

```
日常：嚣张（60%）→ 轻蔑（30%）→ 烦躁（10%，无人理他会烦躁）
战斗：自信（50%）→ 震惊（30%）→ 怨恨（20%，败后）
危机：轻敌（40%）→ 恐惧（30%）→ 疯狂（30%，狂兽体失控）
```

### 情感触发点

| 触发情境 | 情感反应 | 外部表现 |
|---------|---------|---------|
| 被人小看 | 愤怒+轻蔑 | 冷笑，嘲讽 |
| 遇到强敌 | 警惕+不服 | 握紧武器，咬牙 |
| 背后有人议论 | 多疑+记恨 | 暗中观察，找人报复 |
| 被林玄击败 | 震惊→怨恨→黑化 | 脸色骤变，眼神阴冷 |
| 父亲忽视他 | 自卑+愤怒 | 表面不动，背后更嚣张 |
| 苏婉看他一眼 | 紧张+讨好→被拒后恼羞成怒 | 先是试图表现，被冷落后翻脸 |

## 成长弧光

### 第1-5章：嚣张期
- 状态：外门小霸王，淬体五重
- 行为：公开挑衅林玄，设生死擂台
- 心态：轻敌，认为林玄是蝼蚁
- 结局：首战失败，记恨，开始黑化

### 第6-15章：黑化期
- 行为：暗中报复，勾结血海宫，设更多陷阱
- 心态：怨恨，认为林玄作弊或有靠山
- 转折：发现林玄的混沌体，想抢夺
- 关键事件：第3章首战败北；第8章左右被林玄再次击败

### 第16-30章：反派期/崩溃期
- 行为：成为血海宫棋子，不惜一切代价对付林玄
- 心态：被利用而不自觉，彻底迷失
- 结局：第30章左右被清算（死亡或废掉修为）

## 创作检查清单

写赵霸时，检查以下项目：

- [ ] 对话是否带有嘲讽语气？
- [ ] 是否使用「呵」「哼」等语气词？
- [ ] 面对强敌是否轻敌？
- [ ] 是否体现「记仇」特质？
- [ ] 被击败后是否有黑化倾向？
- [ ] 是否避免正面表达情感（特别是自卑）？
- [ ] 狂兽体觉醒时是否有失去理智的描写？
- [ ] 对苏婉的态度是否体现了「求而不得→恼羞成怒」？
