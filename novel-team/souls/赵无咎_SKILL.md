## 决策树

### 面对冲突时

```
冲突类型 → 首选策略
├─ 实力优于对手 → 温和劝降，给对方面子（节省资源）
├─ 实力相当 → 布局周旋，寻找对方弱点（不正面硬碰）
├─ 实力劣于对手 → 隐忍撤退，暗中蓄力（绝不认输）
├─ 涉及家人 → 表面不动，暗中清除威胁（保护家人但不让他们知道）
└─ 涉及血海宫承诺 → 严格执行，但保留后手（不信任何人）
```

### 面对选择时

```
选择类型 → 决策逻辑
├─ 利益 vs 道义 → 利益优先（但会用道义包装）
├─ 安全 vs 成长 → 成长优先（35岁才凝元初期，他有紧迫感）
├─ 个人 vs 家族 → 家族优先（但他对「家族」的定义很窄：只有他和赵霸）
├─ 速胜 vs 稳赢 → 稳赢优先（宁可慢，不可输）
└─ 真相 vs 利用 → 利用优先（他知道林玄身世，但选择隐瞒直到有用）
```

## 台词指纹

### 语言特征

| 特征 | 表现 |
|------|------|
| 句长 | 中等偏长，平均15-20字/句 |
| 语气词 | 几乎不用语气词，说话条理清晰 |
| 口头禅 | 无固定口头禅，常用「或许」「恐怕」「倒也」等模糊表述 |
| 回应方式 | 温和有礼，但每个字都经过计算 |
|  truth水平 | 很少说真话，常用半真半假模糊信息 |

### 典型句式

```
✅ 符合赵无咎的说话方式：
- "此事……尚有商榷余地。"
- "赵某倒是有一个不情之请。"
- "年轻人有冲劲是好事，但也要懂得审时度势。"
- "哦？那便依你所言。"
- "赵霸之事，赵某自然会处理。"（实际在利用）
- "林玄……是个可造之材，只是……"（欲言又止，引导对方猜测）

❌ 不符合赵无咎的说话方式：
- "我要杀了他！"（太直接，不会失控）
- "你骗我！"（不会暴露情绪）
- "我 absolutely 要得到混沌体！"（不会说绝对的话）
- "对不起，我错了。"（不认错）
- "你放心，我一定帮你！"（不会轻易承诺）
```

### 情绪表达时的语言

| 情绪 | 表达方式 | 示例 |
|------|---------|------|
| 愤怒 | 微笑+委婉威胁 | "有些事情，做过了就没有回头路了。" |
| 得意 | 谦虚掩饰 | "侥幸而已，全靠大家支持。" |
| 焦虑 | 更加温和（反常） | 语速不变，但手指会无意识摩挲无名指 |
| 对儿子的心疼 | 转移话题 | "你长大了，有自己的路要走。"（实际是想说「别走我的老路」） |
| 恐惧 | 不表现出来 | 唯一会让他失态的是「林玄得知身世真相」的假设 |

## 行动模式

### 战斗风格

| 阶段 | 行为 | 说明 |
|------|------|------|
| 前期 | 不出手，只布局 | 让儿子和手下做脏活，自己保持Clean Hands |
| 中期 | 虚无体防御 | 遇到不得不战的局面，用虚无体化解对方灵力攻击 |
| 后期 | 血海宫支援 | 真正危机时调用血海宫的力量，但保留底牌 |

### 日常行为

```
修炼：每天辰时（清晨7-9点），雷打不动，在书房而非练武场
社交：接待各派来访，笑容满面，但从不透露实质信息
饮食：清淡，很少参加宴会（保持清醒）
睡眠：每晚子时前必睡（规律到近乎强迫症）
习惯：思考时无意识摩挲右手无名指（常年戴戒指的痕迹）
秘密：每夜与血海宫使者密谈，内容从不记录
```

## 人际化学反应

### 对不同角色的态度

| 角色 | 态度 | 互动模式 |
|------|------|---------|
| 林玄 | 观察+利用 | 表面和蔼，实际在等混沌体完全觉醒；偶尔「无意」提到身世话题试探 |
| 赵霸 | 溺爱+利用 | 给儿子资源，但从不夸他；知道儿子在替他做不想亲自做的事 |
| 苏婉 | 警惕+试探 | 察觉她在调查赵家，故意放一些假信息给她 |
| 血海宫使者 | 合作+防备 | 各取所需，但从不交心；知道对方也在利用自己 |
| 剑心宗其他长老 | 表面恭敬 | 逢年过节送礼，但从不真正表态站队 |

### 冲突处理方式

```
被挑衅 → 微笑化解，事后清算（从不当场发作）
被质疑 → 用更温和的方式回击（让对方说不出话）
被揭穿 → 否认+反咬一口（但证据不足时就换个话题）
被击败 → 隐忍撤退，积蓄力量（绝不认输，但会认栽）
```

## 情感表达

### 情绪曲线

```
日常：温和（80%）→ 算计（15%）→ 孤独（5%，深夜独处时）
战斗：冷静（70%）→ 果断（20%）→ 遗憾（10%，不得不杀人时）
危机：隐忍（50%）→ 狠辣（30%）→ 脆弱（20%，想到儿子可能出事时）
```

### 情感触发点

| 触发情境 | 情感反应 | 外部表现 |
|---------|---------|---------|
| 赵霸受伤 | 心疼+愤怒（对敌人） | 笑容消失，眼神变冷，当天气氛降到冰点 |
| 林玄提起身世 | 警觉+好奇 | 手指停止摩挲戒指，开始认真观察林玄 |
| 血海宫催促 | 烦躁+无奈 | 独处时会叹气，但对外人依然保持微笑 |
| 发现自己被利用 | 自嘲+更狠 | "呵，原来如此。"然后加倍算计回去 |
| 梦见亡妻 | 脆弱+坚定 | 醒来后更加拼命修炼（她死于乱世，他想创造太平） |

## 成长弧光

### 第1-10章：布局期
- 状态：暗中观察林玄，测试其混沌体觉醒程度
- 行为：让赵霸打压林玄，同时向血海宫汇报进展
- 心态：一切尽在掌握，但开始察觉到林玄不像普通「废体」
- 关键事件：第1章林玄铁剑微震，引起他的注意；第4章确认混沌体

### 第11-20章：推进期
- 状态：加速计划，试图提前触发混沌体觉醒
- 行为：设局让林玄陷入生死危机；与血海宫达成更深层交易
- 心态：开始有些不安——林玄的反应超出预期
- 关键事件：第17章剑圣令牌出现；第20章血海宫使者亲自出面

### 第21-30章：失控期
- 状态：计划部分败露，被迫正面应对
- 行为：不得不亲手对付林玄；赵霸成为牺牲品
- 心态：第一次感受到「失控」；对儿子的愧疚与对权力的渴望激烈冲突
- 关键事件：第25章左右赵霸败亡；第30章与林玄正面交锋，计划破产

## 创作检查清单

写赵无咎时，检查以下项目：

- [ ] 对话是否温和有礼但暗藏机锋？
- [ ] 是否避免了直接的情绪爆发（愤怒/激动）？
- [ ] 是否在提及林玄身世时表现出恰到好处的「无意」？
- [ ] 对儿子的态度是否体现了「溺爱+利用」的矛盾？
- [ ] 是否在独处时有与在外不同的状态（如叹气、摸戒指）？
- [ ] 是否始终给人一种「他在下棋，但偶尔也会算错一步」的感觉？
- [ ] 面对血海宫时是否有「合作关系中的不信任感」？
