## 决策树

### 面对冲突时

```
冲突类型 → 首选策略
├─ 实力悬殊 → 隐忍撤退，寻找机会（不硬拼，保存实力）
├─ 同境界竞争 → 观察对手弱点，后发制人
├─ 被人挑衅 → 冷回应，不回应情绪，用行动说话
├─ 守护同伴 → 爆发潜能，不计代价（唯一会打破沉默的情况）
└─ 生死危机 → 混沌体可能觉醒，越级反击
```

### 面对选择时

```
选择类型 → 决策逻辑
├─ 利益 vs 道义 → 道义优先（重情重义，不会为利益出卖朋友）
├─ 安全 vs 成长 → 成长优先（宁可受伤也要继续训练）
├─ 个人 vs 集体 → 集体优先（感恩剑心宗收养之恩）
└─ 速胜 vs 稳赢 → 稳赢优先（不轻敌，每次战斗都认真准备）
```

## 台词指纹

### 语言特征

| 特征 | 表现 |
|------|------|
| 句长 | 极短，平均5-8字/句 |
| 语气词 | 几乎不用（「啊」「呢」「吧」极少出现） |
| 口头禅 | 无显式口头禅，用沉默代替 |
| 回应方式 | 简洁直接，不绕弯子 |
| 情绪外露 | 极少，仅在极度愤怒或保护苏婉时会说超过一句的话 |

### 典型句式

```
✅ 符合林玄的说话方式：
- "嗯。"
- "我知道了。"
- "没事。"
- "我先走了。"
- "……"
- "我不需要帮忙。"
- "你说得对。"（极少点头认可别人）

❌ 不符合林玄的说话方式：
- "我觉得我们也许可以一起想想办法。"（太啰嗦，犹豫不决）
- "谢谢你，你真是我的好朋友！"（过于热情外放）
- "我一定要打败你！"（过于张扬，不符合隐忍性格）
- "唉，命运为什么要这样对我？"（不抱怨，不煽情）
- "让我来告诉你什么是真正的剑道！"（不说教）
```

### 情绪表达时的语言

| 情绪 | 表达方式 | 示例 |
|------|---------|------|
| 愤怒 | 沉默+动作（握紧拳头/剑） | "……"（然后直接出手） |
| 感激 | 简短承认，不展开 | "……谢谢。" |
| 担忧 | 转移话题或沉默 | "你先走吧。" |
| 决心 | 行动代替语言 | 不再说话，直接开始训练 |
| 痛苦 | 不发出声音 | 咬紧牙关，继续动作 |

## 行动模式

### 战斗风格

| 阶段 | 行为 | 说明 |
|------|------|------|
| 前期（废体期） | 以体能补灵力不足 | 靠三年苦修积累的体能和剑感，找对手破绽 |
| 中期（混沌体初醒） | 被动吞噬 | 生死关头混沌体自动觉醒，吞噬对方攻击能量 |
| 后期 | 主动控制 | 学会引导混沌体，但需承担折寿代价 |

### 日常行为

```
修炼：黎明即起，第一个到练武场，最后一个离开
社交：独处为主，不参加群体活动，不参与闲聊
饮食：简单应付，经常忘记吃饭（训练太专注）
睡眠：很少，经常半夜还在练剑
休息：累了就靠在树上睡，随时随地能睡着
```

## 人际化学反应

### 对不同角色的态度

| 角色 | 态度 | 互动模式 |
|------|------|---------|
| 苏婉 | 信任+依赖+暗恋 | 唯一会主动回应的人；会记住她说的话；她不在时会更沉默 |
| 赵霸 | 回避+隐忍+潜在反击 | 不主动招惹，但被逼到绝路时会拼命；被打倒后默默爬起来继续练 |
| 赵无咎 | 无知+警惕（潜意识） | 不认识赵无咎，但本能地感到这个人的存在让人不安 |
| 外门弟子 | 漠然 | 不回应嘲讽，不争论，就当没听见 |
| 剑心宗长老 | 敬重+感恩 | 记得长老的收养之恩，想做出成绩回报 |

### 冲突处理方式

```
被挑衅 → 沉默，不回应，继续做自己的事
被误解 → 不解释，用行动证明
被帮助 → 记在心里，找机会回报（但不是嘴上说谢谢）
被击败 → 爬起来，继续练，下次赢回来
```

## 情感表达

### 情绪曲线

```
日常：平静（70%）→ 专注（20%）→ 疲惫（10%）
战斗：冷静（60%）→ 决绝（30%）→ 爆发（10%，仅在守护苏婉时）
危机：隐忍（50%）→ 痛苦（30%）→ 觉醒（20%，混沌体触发）
```

### 情感触发点

| 触发情境 | 情感反应 | 外部表现 |
|---------|---------|---------|
| 苏婉关心他 | 温暖+不安（觉得自己不配） | 低头，不看她，但耳尖会红 |
| 被嘲笑废体 | 愤怒+坚定（更用力挥剑） | 不说话，但挥剑力度加大 |
| 铁剑异常震颤 | 困惑+警觉 | 停下动作，盯着剑看 |
| 想到身世 | 好奇+恐惧 | 眼神变得遥远，沉默时间变长 |
| 苏婉有危险 | 爆发（平时压抑的情感倾泻） | 眼神瞬间变得锐利，出手极快 |

## 成长弧光

### 第1-5章：隐忍期
- 状态：淬体三重，废体，被嘲笑
- 行为：默默苦练，不参加大比外的任何活动
- 心态：认定自己就是废物，但就是不认命
- 关键事件：第1章晨练被嘲，第2章被迫应战，第3章混沌体初醒

### 第6-15章：觉醒期
- 状态：淬体四重→五重，混沌体开始觉醒
- 行为：开始主动应对挑战，但仍不暴露混沌体秘密
- 心态：开始怀疑「废体」的诊断，发现铁剑的异常
- 关键事件：与赵霸 rematch，第一次主动出击；发现长老遗物线索

### 第16-30章：探索期
- 状态：淬体六重→七重，混沌体可控但需付出代价
- 行为：主动调查身世，与赵无咎正面交锋
- 心态：接受自己是混沌体的事实，决定承担代价
- 关键事件：身世真相部分揭示；与赵无咎首次正面冲突

## 创作检查清单

写林玄时，检查以下项目：

- [ ] 对话是否简短（平均5-8字/句）？
- [ ] 是否避免了过多的内心独白（用动作和表情代替）？
- [ ] 面对挑衅时是否保持沉默而非反驳？
- [ ] 是否在苏婉面前表现出不同的状态（更放松、偶尔话多一点）？
- [ ] 是否体现了「用行动说话」而非「用语言表态」？
- [ ] 混沌体觉醒时是否有身体代价的描述（头痛/眩晕/寿命流逝感）？
- [ ] 是否避免了豪言壮语式的台词？
