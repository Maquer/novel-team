# 《辅助之道》大纲规划

## 基础信息
- **书名**：辅助之道
- **题材**：玄幻爽文
- **平台**：番茄小说
- **目标字数**：100万字+（约300-400章）
- **风格**：轻松爽文，节奏明快
- **核心设定**：主角研发辅助工具，以辅助之道登顶巅峰（金手指始终隐藏）

## 主线架构

### 第一卷：初露锋芒（1-30章）
**核心冲突**：杂役身份 vs 隐藏实力
**爽点节奏**：
- Ch1-3：炼丹展示，引起注意但无人知晓是主角功劳
- Ch5-10：阵法入门，解锁新模块（暗中变强）
- Ch15-20：宗门测试，一鸣惊人但保持低调
- Ch25-30：阁主暗中观察，主角继续隐藏

### 第二卷：天机崛起（31-80章）
**核心冲突**：被多方势力觊觎，主角需谨慎周旋
**爽点节奏**：
- 研发更高级辅助工具
- 建立自己的辅助流派（暗中）
- 与其他势力碰撞但保持低调

### 第三卷：大陆争锋（81-150章）
**核心冲突**：辅助之道 vs 传统修炼
**爽点节奏**：
- 公开挑战传统门派（阶段性展现实力）
- 证明辅助路线的价值
- 统一辅助体系

### 第四卷：巅峰之路（151-250章）
**核心冲突**：对抗上古势力
**爽点节奏**：
- 揭示上古阵法师传承真相
- 帮助更多弱者崛起
- 建立新的修炼秩序

### 第五卷：问道永恒（251-400章）
**核心冲突**：超越凡俗，触摸天道
**爽点节奏**：
- 辅助之道达到极致
- 创造属于自己的时代

## 爽点设计

| 层级 | 频率 | 内容 |
|------|------|------|
| L1 | 每章 | 小工具解锁/炼丹成功/阵法突破 |
| L2 | 每5章 | 解决一个难题/获得重要资源 |
| L3 | 每20章 | 打脸嘲讽者/证明自身价值 |
| L4 | 每卷末 | 颠覆认知的大事件 |

## 关键转折点
1. **Ch1**：炼丹首秀，展示辅助能力（秘密隐藏）
2. **Ch10**：阵法入门，解锁新模块
3. **Ch30**：阁主暗中观察，主角继续低调
4. **Ch100**：公开挑战传统门派（阶段性展露）
5. **Ch200**：统一辅助体系
6. **Ch300**：超越凡俗

## 人物关系

### 林辰（主角）
- 性格：专注、低调、内心有傲骨
- 目标：证明辅助之道可登顶
- 金手指：上古阵法师传承 + 自主研发的辅助工具（**始终隐藏**）
- 成长路线：杂役 → 内门弟子 → 天机阁核心 → 大陆知名 → 开宗立派

### 重要配角
- 张师兄：第一章出场的受益者，后成为林辰支持者（不知真相）
- 白发老者（天机阁阁主）：第一个察觉异常的人，选择**秘密观察**
- 苏婉：同门师姐，早期支持者
- 赵无极：后期反派，传统修炼派的代表
