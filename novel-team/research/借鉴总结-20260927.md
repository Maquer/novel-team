## 已完成（P0）

### 1. 去AI味检测工具 v3

**文件**：`tools/novel-humanizer.py`（31KB）

**整合内容**：
- lieflat 11条实测规则（已验证）
- Novel-Creator 7大类检测（小说专用）
- Tier 1A/1B分层机制
- 两遍式润色Prompt生成

**核心功能**：
```bash
# 检测AI痕迹
python3 novel-humanizer.py < chapter.md

# 生成JSON报告
python3 novel-humanizer.py --json < chapter.md

# 生成润色Prompt
python3 novel-humanizer.py --prompt --chapter-file chapter.md
```

**检测类别**：
| 来源 | 类别 | 数量 |
|------|------|------|
| lieflat | 翻案腔、顿号罗列、相邻句同款、破折号、冒号、序数词、拟人化、数据概括、名词化、起手式、翻译腔、段首评论 | 11条 |
| Novel-Creator | AI高频词、弱化副词、意义膨胀、结论套话、论文结构、正式语体、排比三连 | 7类 |

**分级标准**：
- 0分：✅ 干净
- 1-5分：🟢 极轻
- 6-15分：🟡 轻微AI味
- 16-25分：🔴 明显AI味
- >25分：🚨 严重AI味，建议重写

## 已完成（P1）

### 2. 知识图谱构建器

**文件**：`tools/story-graph.py`（13KB）

**借鉴来源**：Novel-Creator story_graph_builder.py

**节点类型**：
- character（角色）
- location（地点）
- faction（势力）
- item（物品）
- event（事件）
- foreshadow（伏笔）
- worldrule（世界观规则）
- power_system（力量体系）

**边类型**：
- ally（同盟）
- enemy（敌对）
- mentor（师徒）
- subordinate（从属）
- romantic（情感）
- belongs_to（归属）
- located_at（位于）
- triggers（引发）
- foreshadows（铺垫）
- owns（持有）

**核心功能**：
```bash
# 添加节点
python3 story-graph.py add-node --type character --name "林动"

# 添加边
python3 story-graph.py add-edge --type owns --source "林动" --target "神秘玉佩"

# 列出节点/边
python3 story-graph.py list-nodes
python3 story-graph.py list-edges

# 导出图谱
python3 story-graph.py export --format mermaid

# 校验图谱
python3 story-graph.py validate

# 生成报告
python3 story-graph.py report
```

### 3. RAG剧情检索器

**文件**：`tools/rag-retriever.py`（8KB）

**借鉴来源**：Novel-Creator plot_rag_retriever.py

**核心功能**：
```bash
# 建立索引
python3 rag-retriever.py build --project-dir /path/to/project

# 搜索相关章节
python3 rag-retriever.py search --project-id my-novel --query "林动 玉佩"

# 查看索引状态
python3 rag-retriever.py status
```

**检索流程**：
1. 查询触发判断（实体/关键词匹配）
2. BM25风格粗筛（token重叠度）
3. 语义重排精筛（实体加成）
4. 上下文建议生成
