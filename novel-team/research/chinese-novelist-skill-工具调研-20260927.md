## 三、核心功能详解

### 3.1 三层递进式问答

**Layer 1 — 核心定位（必答，3问）**：
- Q1：题材创意（悬疑/言情/奇幻/科幻/历史等）
- Q2：主角设定（男/女/双主角/群像）
- Q3：核心冲突（生死存亡/查明真相/复仇雪恨等）

**Layer 2 — 深度定制（可选，5问）**：
- Q4：世界观
- Q5：叙事视角
- Q6：核心主题
- Q7：读者定位
- Q8：章节数量

**Layer 3 — 标题生成**：
- AI基于创意元素生成候选标题
- 用户选择或自定义

### 3.2 创作记忆系统

```json
{
  "preferred_genres": ["悬疑推理", "都市现实"],
  "narrative_style": "第一人称",
  "chapter_count_preference": 20,
  "writing_density": "中等",
  "hook_preference": "悬念型结尾"
}
```

**价值**：
- 跨会话学习用户偏好
- 下次创作直接应用习惯
- 省去重复问答

### 3.3 中断续写机制

```python
# 检测逻辑
if project_dir exists and has unfinished chapters:
    show "检测到未完成项目，是否续写？"
    if user confirms:
        load last_chapter
        read current_state
        continue from breakpoint
```

### 3.4 自动校验与修复

**校验流程**：
1. 读取 `02-写作计划.json`
2. 逐章检查：
   - 文件存在性
   - 字数检查（≥3000字）
   - 连贯性检查
3. 汇总结果：
   - 全部通过 → 状态"completed"
   - 有不通过 → 进入修复流程

**修复机制**：
- 最多3轮校验-修复循环
- 每轮重新执行创作流程
- 超过3次仍不合格 → 保留记录但不阻塞

### 3.5 字数检查脚本

```bash
# 检查单个章节
python check_chapter_wordcount.py 第01章.md

# 检查所有章节
python check_chapter_wordcount.py --all ./novel/

# 自定义最小字数
python check_chapter_wordcount.py --all ./novel/ 3500
```

**功能**：
- 统计中文字数（排除标点符号和Markdown标记）
- 提取正文内容（排除标题等元数据）
- 生成检查报告

## 六、关键发现

### 6.1 Skill模式的创新性

chinese-novelist-skill采用**Skill模式**，核心价值在于：
- 不依赖特定平台（适配Claude Code/Codex/Cursor等）
- 纯Markdown+Python实现，零第三方依赖
- 流程文档化，易于理解和扩展

### 6.2 三层问答的精妙设计

```
Layer 1（必答）：快速确定核心定位
Layer 2（可选）：深度定制满足个性化需求
Layer 3（生成）：AI辅助标题创作
```

这种设计既保证了效率（快速跳过），又满足了深度需求（可选定制）。

### 6.3 创作记忆系统的价值

> "下次创作直接应用习惯，省去重复问答"

这是非常实用的设计，解决了用户每次都要重新说明偏好的痛点。

### 6.4 自动校验修复的工程化

```
校验 → 不合格 → 重写（最多3轮）→ 再次校验
```

这是一个经典的容错机制，确保输出质量。
