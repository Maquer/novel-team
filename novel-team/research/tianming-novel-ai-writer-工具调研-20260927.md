## 二、核心机制

### 2.1 闭环写作流程

```
写前读取 → AI 写作 → 门禁校验 → 正文落地 → 状态回写 → 下一章读取最新状态
```

**关键洞察**：第3001章看到的是第3000章落地后写入的真实字段值，而不是模型模糊回忆。

### 2.2 15维事实快照

| 维度 | 追踪内容 | 示例 |
|------|---------|------|
| 角色状态 | 境界、能力、关系网 | 张三·筑基期·会御剑术 |
| 角色位置 | 每个角色当前所在地点 | 张三·正在·烈焰谷 |
| 角色外貌 | 发色、瞳色、外观特征 | 防止AI写出矛盾描写 |
| 冲突进度 | 每条冲突线的当前状态 | 正邪大战·进行中 |
| 伏笔状态 | 已埋/未收/逾期，分Tier统计 | 假死真相·已埋·未收·Tier-1 |
| 剧情节点 | 按章归档的关键事件 | 第87章·张三叛出宗门 |
| 地点状态 | 地点当前状况 | 烈焰谷·已被封印 |
| 势力状态 | 势力当前状况 | 天剑宗·内乱中 |
| 时间线 | 章节时段、经过时间 | 检测时序冲突 |
| 物品状态 | 物品持有者和状态 | 天命剑·张三持有·active |
| 世界观硬约束 | 不可违反的规则 | "凡人不可飞行"→硬约束 |
| 地点特征 | 地点描述与环境细节 | 防止场景描写前后矛盾 |
| 秘密状态 | 知情角色列表与揭露状态 | 假死真相·知情人：无·hidden |
| 誓约约束状态 | 约束条件、违约后果 | 追踪承诺兑现与违约 |
| 截止约束状态 | 倒计时任务的截止时间 | 追踪时间压力类剧情 |

### 2.3 12类变更声明（CHANGES）

每章必须交付的12类变更：

| 变更类型 | 记录内容 |
|---------|---------|
| 角色状态变化 | 境界/等级、新增能力、失去能力、心理状态、关键事件、关系变化 |
| 冲突进度 | 冲突ID、新状态、推进事件 |
| 新剧情节点 | 关键词、上下文摘要、涉及角色、所属故事线 |
| 伏笔动作 | 伏笔ID、动作类型（埋设setup/回收payoff）|
| 地点状态变化 | 地点ID、新状态、触发事件 |
| 势力状态变化 | 势力ID、新状态、触发事件 |
| 时间推进 | 当前时段、经过时间、关键时间事件 |
| 角色移动 | 角色ID、出发地→目的地 |
| 物品流转 | 物品名称、原持有者→新持有者 |
| 秘密揭示 | 秘密ID、新知情角色列表、揭露方式 |
| 誓约约束变化 | 誓约ID、变化动作、相关角色 |
| 截止约束变化 | 截止ID、变化动作、触发条件、倒计时截止时间 |

### 2.4 六道生成门禁

| 关卡 | 检查内容 |
|------|---------|
| 1. 协议解析 | AI输出必须包含`---CHANGES---`分隔符+完整JSON变更声明 |
| 2. 引用校验 | CHANGES中引用的角色、地点、势力ID必须在设计数据中存在 |
| 3. 一致性校验 | 角色状态变化、冲突推进、伏笔动作是否与事实快照矛盾 |
| 4. 未知实体检测 | 正文引入的未登记实体：总数>5个，或龙套>3个→打回 |
| 5. 描写一致性 | 正文中角色外貌描写是否与角色档案矛盾 |
| 6. 蓝图出场检查 | 蓝图指定的角色、势力、地点、剧情关键角色是否在正文中实际出现 |

## 四、关键发现

### 4.1 "不靠上下文，靠状态"的革命性理念

传统AI写作依赖上下文窗口，但上下文窗口有硬限制：
- 上下文越来越长 → 超窗截断 → 早期内容遗忘
- 角色性格漂移 → 设定被稀释
- 伏笔忘了回收 → 无状态追踪

天命的解决方案：**把故事变成系统能管理的数据，让AI按数据写作**。

### 4.2 闭环写作的工程化

```
写前读取 → AI写作 → 门禁校验 → 正文落地 → 状态回写 → 下一章读取最新状态
```

这与我们之前的"上下文管理"理念一致，但更加工程化：
- 每章必须有CHANGES声明
- CHANGES必须穿过6道门禁
- 通过后才能更新事实快照
- 下一章读取的是真实字段值，不是模型回忆

### 4.3 15维快照的完整性

从角色状态到誓约约束，15个维度覆盖了小说创作的所有关键状态：
- 角色维度：状态、位置、外貌
- 剧情维度：冲突、伏笔、剧情节点
- 世界维度：地点、势力、时间
- 物品维度：物品状态
- 规则维度：世界观硬约束
- 秘密维度：秘密状态
- 承诺维度：誓约约束、截止约束

### 4.4 六道门禁的严谨性

从协议解析到蓝图出场检查，6道门禁确保了：
1. 输出格式正确（协议解析）
2. 引用完整性（引用校验）
3. 逻辑一致性（一致性校验）
4. 实体可控性（未知实体检测）
5. 描写一致性（描写一致性）
6. 计划执行度（蓝图出场检查）
