## 一、主角命名规律

### 1.1 玄幻类（斗破苍穹、玄鉴仙族）

**姓氏特征**：
```
高频姓：萧、林、叶、楚、陈、李
罕见姓：欧阳、端木、尉迟、赫连、慕容
```

**名字特征**：
```
单名：辰、炎、动、凡、逸、尘、渊、寒、龙、虎、牛
双名：逸尘、轩辕、寒渊、凌天、星辰
```

**命名公式**：
```
公式1：属性+名（萧炎=火，林动=木）
公式2：气势+名（萧辰=星辰，叶凡=平凡中见不凡）
公式3：辈分+名（李景龙、李景虎、李景牛）
```

**成功案例**：
| 姓名 | 作品 | 特点 | 适用风格 |
|------|------|------|---------|
| 萧辰 | 原创 | 星辰不凡 | 热血升级流 |
| 叶凡 | 遮天 | 平凡中见不凡 | 写实玄幻流 |
| 林逸尘 | 原创 | 超脱尘世 | 仙侠修真流 |
| 李景龙 | 玄鉴仙族 | 家族辈分 | 家族群像流 |

### 1.2 历史类（我的公公叫康熙）

**姓氏特征**：
```

汉族姓：舒、齐、福、苏、王、李
```

**名字特征**：
```

**命名公式**：
```

公式3：单名+寓意（齐锡=齐整+锡铁）

**成功案例**：

| 舒舒 | 康熙 | 叠字亲切 | 历史穿越文 |

| 福松 | 康熙 | 满汉融合 | 旗人角色 |

## 五、命名禁忌

### 5.1 避免的命名

**过于常见的**：
- ❌ 张三、李四、王五（打酱油三人组）
- ❌ 张伟、王芳、李娜（现实中太多）

**过于中二的**：
- ❌ 灭世、诛神、弑天（除非是搞笑文）

- ❌ 欧阳司马、端木铜铁（念都念不过来）
- ❌ 生僻字（读者不认识）

## 七、命名趋势总结

### 7.1 玄幻类命名趋势

1. **单名为主**：萧炎、林动、叶凡（简洁有力）
2. **属性关联**：萧炎（火）、林动（木）（增强记忆点）
3. **气势感强**：辰、轩、逸、尘、渊（有张力）
4. **少见姓**：萧、林、叶、楚（避免大众化）

### 7.2 历史类命名趋势

1. **叠字亲切**：舒舒（易记有亲和力）
2. **满汉融合**：郭络罗桂丹（体现身份）
3. **辈分清晰**：李景龙、李景虎（家族感）
4. **寓意明确**：齐锡（整齐+坚韧）
