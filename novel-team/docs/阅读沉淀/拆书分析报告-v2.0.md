## 三、命名规律汇总

### 3.1 主角命名规律

**玄幻类（推荐）**：
```
姓氏：萧、林、叶、楚、陈、周、石
名字：辰、炎、动、凡、逸、尘、渊、寒、青、昊
示例：萧辰、叶凡、林逸尘、周青、石昊
```

**历史类（不建议）**：
```
姓氏：舒、齐、福
名字：叠字（舒舒）、单名（齐锡）
示例：舒舒、齐锡
```

**家族类（可借鉴）**：
```
姓氏：李
名字：景字辈（景龙、景虎、景牛）
特点：辈分清晰、家族感强
```

### 3.2 反派命名规律

**压迫感型**：
```
用字：煞、魔、阴、邪、枭、霸、烈、血、冥、鬼
示例：王傲天、血无痕、阴九幽、厉天霸
```

**普通型（底层爪牙）**：
```
用字：旺、福、财、贵、大、四
示例：王大、李四、张旺
```

### 3.3 配角命名规律

**师兄/伙伴类**：

玄幻：苏逸、顾长风、沈星河

## 四、核心发现总结

### 4.1 开篇节奏黄金法则

**前150字要有冲突**：
- 斗破：被嘲讽"废物"
- 夜无疆：残酷生存环境
- 遮天：九龙拉棺+危机
- 完美世界：天才被打脸

**前500字要有金手指预告**：
- 斗破：戒指里的老爷爷
- 夜无疆：系统提示音
- 遮天：荒古圣体+不死经文
- 完美世界：盘龙戒指+内天地

**每150-200字一个小高潮**：
- 快节奏作品都符合这个规律
- 中节奏作品可以适当放宽
- 慢节奏作品不适合网文

### 4.2 命名黄金法则

**主角名**：
- ✅ 少见姓+有气势名
- ✅ 读起来有力量感
- ✅ 符合角色性格

**反派名**：
- ✅ 压迫感用字（煞、魔、霸）
- ✅ 与普通村民区分
- ✅ 不要"张三李四"

**配角名**：
- ✅ 师兄：洒脱豪爽（苏逸、顾长风）
- ✅ 师妹：清冷高贵（冷如霜、慕容雪）

### 4.3 节奏黄金法则

**推荐节奏**：
- ✅ 快节奏（每150-200字高潮）
- ✅ 中等节奏（每300-500字高潮）

**避免节奏**：
- ❌ 慢节奏（多代叙事、铺垫过长）
- ❌ 过于平淡（没有冲突）
