## 二、岗位能力矩阵

### 2.1 主笔作者（Content Lead）

**核心能力要求**：
- 三级提示词覆盖（内置/全局/项目）
- 三阶段创作流程
- 上下文管理（RTCO框架）
- 字数控制
- 剧情分析服务
- 多维度剧情评分

**职责范围**：
- 负责关键章节（开篇、高潮、结局）创作
- 把控整体文风和叙事节奏
- 指导辅助作者创作方向
- 处理复杂剧情转折

**对应工具**：
```
tools/
├── context-manager.py      # 上下文管理
├── plot-analyzer.py        # 剧情分析服务
├── plot-simulation-v2.py   # 多维度剧情评分
├── wordcount-check.py      # 字数控制
└── prompt-library/         # 提示词库
```

### 2.2 辅助作者（Content Writer）

**核心能力要求**：
- 批量改词工具
- 合并导出工具
- 字数检查脚本
- 后处理工具（逗号清理+标点注入）

**职责范围**：
- 常规章节创作（过渡章节、日常剧情）
- 根据大纲和提示词续写
- 章节润色和优化
- 批量文本处理

**对应工具**：
```
tools/
├── batch-replace.py        # 批量改词
├── merge-chapters.py       # 合并导出
├── wordcount-check.py      # 字数检查
├── clean_commas.py         # 逗号清理
└── inject_punctuation.py   # 标点注入
```

### 2.3 世界观师（World Builder）

**核心能力要求**：
- 世界包管理系统（23种条目+30种关系）
- 一致性检查系统
- 15维事实快照系统
- 知识图谱
- RAG检索器

**职责范围**：
- 维护世界包数据（地理、势力、物品等）
- 确保世界设定一致性
- 管理知识图谱和事实账本
- 提供RAG检索支持

**对应工具**：
```
tools/
├── world-pack.py           # 世界包管理
├── world-init.py           # 世界初始化
├── fact-snapshot.py        # 15维事实快照
├── story-graph.py          # 知识图谱
└── rag-enhanced.py         # 增强RAG检索
```

### 2.4 大纲设计师（Outline Designer）

**核心能力要求**：
- 三级大纲系统（作品→卷→章节→场景）
- 状态回写机制
- 六道门禁校验框架
- 多模型剧情推演
- 伏笔管理系统
- 合同树程序校验

**职责范围**：
- 制定三级大纲（作品级/卷级/章级）
- 管理伏笔和钩子
- 进行剧情推演和选优
- 确保大纲一致性

**对应工具**：
```
tools/
├── outline.py              # 三级大纲系统
├── outline-builder.py      # 大纲构建器
├── fact-snapshot.py        # 状态回写
├── plot-simulation-v2.py   # 剧情推演
├── foreshadow-service.py   # 伏笔管理
└── contract-tree.py        # 合同树校验
```

### 2.5 审稿编辑（Review Editor）

**核心能力要求**：
- 四道一致性防线
- 结构化审稿（五维检查）
- gate-check.py门禁系统
- 事实账本核验
- 认知分级系统

**职责范围**：
- 执行六道门禁检查
- 审核章节内容一致性
- 核验事实账本
- 确保合规发布

**对应工具**：
```
tools/
├── gate-check.py           # 门禁检查
├── guard-v6.py             # 一致性防线
├── fact-ledger.py          # 事实账本
├── decide-trigger.py       # 决策触发
└── novel-humanizer.py      # 去AI味检测
```

### 2.6 去AI味师（Style Optimizer）

**核心能力要求**：
- 去AI味12条纪律
- 去AI味检测v3（Tier 1A/1B分层）
- 指纹蒸馏引擎
- 硬性约束系统
- 后处理工具链

**职责范围**：
- 执行去AI味检测和修复
- 指纹蒸馏（5源文→公约数）
- 文风优化和打磨
- 执行硬性约束

**对应工具**：
```
tools/
├── anti-ai-12.py           # 去AI味12条
├── novel-humanizer.py      # 去AI味检测v3
├── fusion-engine.py        # 指纹蒸馏
├── guard-v6.py             # 硬性约束
└── clean_commas.py         # 后处理
```

### 2.7 数据分析师（Data Analyst）

**核心能力要求**：
- 创作统计
- 硬账台账（防数值跳变）
- 创作记忆系统
- 时间线管理
- 多模型对比分析

**职责范围**：
- 统计创作数据（字数/进度/效率）
- 监控数值一致性（防跳变）
- 分析创作效果
- 生成日报/周报

**对应工具**：
```
tools/
├── fact-ledger.py          # 硬账台账
├── preference-memory.py    # 创作记忆
├── timeline.py             # 时间线管理
└── capability-evaluator.py # 能力评估
```

### 2.8 团队总监（Team Director）

**核心能力要求**：
- 全局协调能力

**职责范围**：

- 把控整体质量
- 对接外部需求

**对应工具**：

├── decide-trigger.py       # 决策触发

## 三、工作流程设计

### 3.1 创作流程（七阶段）

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│  世界构建  │ → │  大纲设计  │ → │  角色创建  │ → │  章节创作  │
│ (世界观师) │   │ (大纲师)  │   │ (辅助作者)│   │ (主笔/辅助)│
└──────────┘   └──────────┘   └──────────┘   └──────────┘
                                              │
                                              ▼
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│  门禁检查  │ ← │  去AI味   │ ← │  审稿编辑  │ ← │  质量优化  │
│ (审稿编辑) │   │ (去AI味师)│   │ (审稿编辑)│   │ (主笔作者)│
└──────────┘   └──────────┘   └──────────┘   └──────────┘
                                              │
                                              ▼
┌──────────┐   ┌──────────┐
│  发布归档  │ ← │  数据统计  │
│ (总监确认) │   │ (数据分析师)│
└──────────┘   └──────────┘
```

### 3.2 协作机制

#### 日循环（Daily Loop）
```
08:00  数据分析师生成日报
09:00  团队总监召开晨会（AI自动）
09:30  大纲设计师更新当日任务
10:00  作者开始创作
12:00  去AI味师检查上午产出
14:00  辅助作者续写
17:00  审稿编辑检查
18:00  数据分析师生成进度报告
```

#### 周循环（Weekly Loop）
```
周一：大纲设计师更新周计划
周三：世界观师检查世界包一致性
周五：团队总监周会，评估进度
周日：数据分析师生成周报
```
