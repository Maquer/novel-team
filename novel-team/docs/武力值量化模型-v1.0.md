## 一、模型设计原则

### 核心公式

```
最终战力 = 基础战力 × (1 + 功法加成) × (1 + 装备加成) × (1 + 心境加成) × (1 + 实战加成)
```

### 设计目标

| 原则 | 目标值 | 说明 |
|------|-------|------|
| **大境界压制** | ≥2.5x | 跨越一个大境界，战力至少提升2.5倍 |
| **小境界递进** | 1.2x-1.5x | 同境界内，小境界差距可控 |
| **可逆性** | 同境界胜率40%-60% | 低境界有机会通过外物/心境战胜高境界 |
| **势力平衡** | ≤1.5x | 同级别势力领袖战力差距不超过50% |

### 关键设计

- **大境界压制**: 每次跨越大境界，基础战力 ×2.5
- **小境界递进**: 同境界内，每小境界提升约1.25-1.33倍
- **淬体期特殊**: 新手期成长曲线平缓，体现"打基础"阶段

| 势力 | 领袖 | 境界 | 基础战力 | 最终战力 |

| 逍遥阁 | 逍遥子 | 元婴初期 | 125,000 | ~216,972 |

**平衡性分析**：
- 三方领袖境界相同（元婴初期）
- 战力差距 <15%，符合势力平衡要求
- 逍遥子略强（活了500年，经验丰富），但不超过50%阈值

## 六、使用方式

### 查看境界表
```bash
python3 tools/power-model-v3.py --table
```

### 查看人物战力
```bash
python3 tools/power-model-v3.py --characters
```

### 比较两人战力
```bash
python3 tools/power-model-v3.py --compare "萧辰" "王大"
python3 tools/power-model-v3.py --compare "李白白" "血煞老祖"
```

### 应用到世界包
```bash
python3 tools/power-model-v3.py --apply ".world-packs/玄天大陆.json"
```

## 七、设计决策记录

| 决策 | 理由 |
|------|------|
| 大境界×2.5 | 体现修仙小说"大境界如隔天堑"的惯例 |
| 小境界×1.25-1.33 | 同境界内竞争仍激烈，保留悬念 |
| 淬体期成长放缓 | 新手期不应过快变强，体现"打基础" |
| 天命剑 Legendary+100% | 主角金手指应有显著加成 |
| 逍遥子略强于宗主 | 中立势力需要足够威慑力维持平衡 |
