### 2.2 阅读目标

**每本小说学习**：
1. **开篇分析**（前3章，约6000字）
   - 开篇方式（冲突/悬念/反转/日常）
   - 前100字是否抓人
   - 前500字是否有第一个高潮
   - 结尾是否有钩子

2. **命名分析**
   - 主角名特点
   - 配角名风格
   - 反派名压迫感
   - 命名规律总结

3. **节奏分析**
   - 多少字出第一个小高潮
   - 多少字出第一个大高潮
   - 平淡段最长不超过多少字
   - 情绪曲线如何设计

4. **细节分析**
   - 环境描写密度
   - 动作描写特色
   - 心理描写频率
   - 对话占比

## 四、沉淀机制（知识管理）

### 4.1 知识库结构

```
docs/阅读沉淀/
├── 开篇分析/
│   ├── 斗破苍穹-开篇分析.md
│   ├── 凡人修仙传-开篇分析.md
│   └── ...
├── 命名分析/
│   ├── 斗破苍穹-命名分析.md
│   ├── 凡人修仙传-命名分析.md
│   └── ...
├── 节奏分析/
│   └── Top10开篇节奏对比.md
├── 命名库/
│   ├── 主角名库.md
│   ├── 配角名库.md
│   └── 反派名库.md
└── 金句库/
    └── 经典开篇金句.md
```

### 4.2 知识应用

**应用路径**：
```
阅读沉淀 → 命名库 → 创作时调用
阅读沉淀 → 开篇模板 → 写作时参考
阅读沉淀 → 节奏模型 → 自检时对照
```

**具体应用**：
1. **命名时**：从命名库选择，不临时造
2. **写开篇时**：参考开篇模板，检查钩子
3. **写节奏时**：对照节奏模型，确保起伏
4. **质检时**：用可读性检查清单，逐项核对
