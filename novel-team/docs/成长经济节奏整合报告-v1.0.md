## 一、总览：Progression-Architect 是什么

一个游戏成长系统 Agent Skill。输入游戏类型+DAU+付费模型，输出货币体系/章节节奏/付费触点/留存目标。核心资产：

1. **三支柱框架**：资源循环（Faucet→Sink→Converter，目标产出/消耗 1.05-1.15）/ 货币体系（软vs硬）/ 商业模式
2. **5 种货币体系模板**：A型单货币（原神）/ B型双货币（AFK）/ C型四层货币（王者荣耀）/ D型SLG资源型（万国觉醒）/ E型战令型（PUBG）
3. **章节节奏模板**：新手期(1-5章)→成长期(6-20)→挑战期(21-50)→长期(50+)，痛苦指数控制：每3-5章1奖励关
4. **付费触点 L1-L4**：基础(即时满足)→中端(性价比)→高端(FOMO)→顶级(稀缺+情感)
5. **留存基准线**：D1 40%+ / D7 20%+ / D30 10%+
6. **7 大亿元级案例方法论**（详见第四节映射）

## 二、为什么这个 Skill 对小说有用

**网文连载就是留存经济。** 章节=关卡，追读率=D1留存，弃书=流失，爽点=里程碑奖励，压抑过渡期=痛苦指数，"追更动力"=战令沉没成本。游戏行业用 20 年时间把"怎么让人自愿每天回来"做成了可量化的科学，这套方法论直接可以平移到连载叙事：

| 游戏概念 | 网文等价物 |
|---------|-----------|
| 关卡难度曲线 | 冲突强度曲线 |
| 奖励关（reward level） | 爽点章（打脸/突破/收获） |
| 痛苦指数（连续失败） | 压抑过渡期（被追杀/闭关/铺垫） |
| 连续失败2次→降难度 | 连续2章压抑→第3章必须给爽点 |
| 留存曲线 D1/D7/D30 | 追读率：首章钩子/30章入坑/200章死忠 |
| 里程碑奖励 | 境界突破/新功法/新地图解锁 |
| Faucet/Sink | 资源产出点/消耗点（灵石、丹药、寿命） |
| 战令赛季 | 卷结构（每卷一个"赛季"，不清零成长，换新目标） |

## 三、六个核心迁移项

### 迁移1：三支柱 → 世界经济显式化（P0）

**支柱1 资源循环 → 玄天大陆 I/O 表**

当前问题：灵石只有兑换率（100下品=1中品），缺来源/去向。按 Skill 核心配平公式 `产出/消耗 ≈ 1.05-1.15（轻微通胀有益）` 落地：

| 资源 | Faucet（产出） | Sink（消耗） | Converter（转化） | 通胀控制 |
|------|---------------|-------------|------------------|---------|
| 下品灵石 | 外门月俸50 / 杂役任务 / 低阶妖兽内丹 | 聚气丹修炼 / 法器维修 / 食宿 | 聚气丹（灵石→修为） | 月俸恒定，任务奖励按境界分层 |
| 中品灵石 | 内门贡献兑换 / 秘境产出 / 筑基期宗门年俸 | 筑基丹药 / 地阶功法 / 洞府灵气阵法 | 天材地宝→炼丹 | 筑基消耗>>练气产出，天然节流 |
| 寿命（硬货币） | 境界延寿（淬体100→炼气150→筑基300→金丹600→元婴1200） | **天命剑激活：每次折寿** | 延寿丹（中品灵石→寿命，低效兑换） | 寿命不可交易，最稳定的"硬货币" |
| 气运（天命值） | 天命剑吸收（击杀气运之子/夺天命之物） | 突破加持 / 剑解封 | 气运→战力（越级挑战的合法性来源） | 气运被夺=反派动机，天然零和 |

**设计原则**：软货币（灵石）可交易可产出，硬货币（寿命/气运）不可交易、只能转化——对齐 Skill"不可交易资源 > 可交易资源（更稳定）"。**天命剑的金手指本质 = 一台寿命↔战力↔气运的 Converter**，这就是它"邪门"的数值学定义。

**支柱2 货币体系 → 玄天大陆选型**：C型四层货币（逐层转化）+ 寿命/气运双硬通货。四层结构：下品灵石（免费）→中品（半硬，需筑基战力门槛）→上品（硬，秘境/大宗才有）→**天命/气运（不可交易顶层）**。逐层转化培养"换汇"情节：主角卖丹攒下品→换中品买功法→换上品买法宝，每一层都是剧情节拍。

**支柱3 商业模式 → 对连载而言是"读者时间投资回报"**：为读者提供"追读进步感"——每章有微回报（新信息/小爽点），每弧有中回报（突破/打脸），每卷有大回报（格局跃迁）。

### 迁移2：章节节奏四阶段 → 五卷节奏元数据（P0）

Skill 模板按"章"设计，天命按 100 万字/5 卷/约 500 章折算（每卷约 100 章）：

| 阶段 | 游戏定义 | 天命对应 | 节奏目标 | 里程碑奖励 | 痛苦指数控制 |
|------|---------|---------|---------|-----------|-------------|
| 新手期 | 1-5章，教学 | **卷1前20章**（淬体→炼气，外门立足） | 教学+熟悉：修炼规则/天命剑机制/三宗格局 | 解锁：天命剑初封、轻身术、内门资格 | 0——每章必须有正反馈 |
| 成长期 | 6-20章，建立习惯 | **卷1后80章+卷2**（炼气→筑基） | 建立习惯：资源循环跑通、势力关系网 | 解锁：秘境（副本）、炼丹、道侣/兄弟线 | 每3-5章1爽点章；被压制不超过2章 |
| 挑战期 | 21-50章，制造差距 | **卷3-卷4**（筑基→金丹→元婴） | 制造差距：三宗大战、天骄争锋、气运之争 | 稀缺资源：天阶功法、剑冢、天裂真相碎片 | 每3-4章1爽点；连续压抑≤2章必须释放 |
| 长期 | 50+章，持续目标 | **卷5**（化神→渡劫，终局） | 持续目标：外神降临、天命剑终极之谜 | 顶级：渡劫、改天换地 | 连续受挫2次→给一次"盟友来援/底牌揭晓"式释放 |

**关键规则（写进大纲工具契约）**：
1. **压抑上限**：连续 2 章无正反馈（未突破/未获得/未打脸/未揭示真相），第 3 章强制安排爽点章——等价于 Skill 的"连续失败2次→降难度"
2. **奖励关节拍**：成长期每 3-5 章、挑战期每 3-4 章必须有一个"里程碑章"
3. **卷=赛季**（对齐万国觉醒 KVK 设计）：每卷结束**不清零**主角成长，只升级对手层级和新目标——避免"换地图功力减半"的网文毒点

### 迁移3：爽点分层 L1-L4（P0）

| 层级 | 付费触点 | 网文爽点等价物 | 触发场景 | 情绪驱动 | 出现频率 |
|------|---------|---------------|---------|---------|---------|
| L1 基础 | 体力/加速 | 小胜利：任务完成、炼丹成功、杂役打脸 | 每章 | 即时满足 | 每章至少1个 |
| L2 中端 | 月卡/战令 | 中收获：境界小成、新功法到手、地位提升 | 每3-5章 | 性价比（"追得值"） | 3-5章1个 |
| L3 高端 | 抽卡/角色池 | 大高潮：秘境夺宝、击败强敌、身世线索、越级挑战 | 每卷2-3次 | FOMO（"不能断更"） | 卷级节拍 |
| L4 顶级 | 限定皮肤/礼包 | 格局跃迁：大境界突破、天命剑解封、三宗格局改变、真相揭示 | 每卷1次 | 稀缺+情感 | 卷末 |

**用法**：大纲设计时每章标注 L1-L4 层级，检查节奏是否塌陷（连续 10 章全 L1 = 平淡；连续 L4 = 疲劳）。这是 outline-precheck.py 可以新增的校验维度。

### 迁移4：原神"树脂控制" → 主角行动力限制（P1）

原神用树脂限制刷本速度=控制节奏。天命已有天然树脂：**寿命（天命剑代价）+ 境界瓶颈**。但要显式化：
- 天命剑每次激活折寿 X 月 → 主角必须"攒够本钱再用剑"，形成"省着用→被逼无奈→爆发→心疼寿命"的循环节拍
- 突破需要时间沉淀（闭关月数）→ 防止升级过快膨胀
- **圣遗物随机深坑启示**：天宝可以"永远差一件"——玄天大陆可以设定"天命剑七片剑魄，每片都不完整"，永远有追求（长线目标，对齐"永远没有完美"）

### 迁移5：AFK 时间锁 + 付费/进度分离 → 修炼世界合理性（P1）

AFK Arena：进度靠时间，付费只加速。修仙世界等价：**高阶修士的"时间积累"不可绕过**（逍遥子500年=重氪玩家？不——他更像"肝帝"）。写作含义：
- 反派不能靠丹药堆到元婴（资源可以买，心境/感悟买不到）→ 境界体系可信度
- 主角优势=天命剑（催化剂）+气运（机会），不是无限资源
- 对齐《凡人修仙传》借鉴结论："资源决定一切，但资源≠境界"

### 迁移6：王者荣耀"贵族锁客+小额破冰" → 连载钩子设计（P2）

- **小额破冰**（6元首充培养付费习惯）= **前3章必须给足爽点完成"入坑破冰"**（对齐拆书结论：前150字冲突、前500字金手指预告）
- **贵族体系月度维持**= 角色名场面/招牌技能反复出现，维持读者情感账户（每次萧辰用天命剑寒芒，都是"贵族权益"提醒）
- **链式消费**（英雄→皮肤→配件）= 目标链设计：突破需要功法→功法需要灵力→灵力需要洞府→洞府需要身份……一环扣一环，永远"差一步就到"

## 七、诚实边界

1. **Progression-Architect 是 1★ 个人 Skill**（2026-03 创建），价值在方法论框架完整，不在案例数据深度——7 案例每个只有 3-5 条 bullet，本报告的映射大部分是我做的领域迁移，非仓库自带
2. **付费触点≠网文收费**：本报告全部迁移只取"留存/节奏"含义，不引入任何"向读者收费"的设计
3. **痛苦指数模型未量化**：游戏里是"连续失败次数"，小说里"压抑"程度无法直接计数，目前用"连续无正反馈章数"做离散近似，够用但粗糙
4. **留存基准线（D1 40%）是游戏行业数据**，网文的"首章-30章-200章"留存实际水位低得多，只作相对比较用
