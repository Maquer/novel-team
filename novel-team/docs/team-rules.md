# 小说团队 · 创作规范文档

> 基于 logic-review.py 逻辑审查门禁 + 世界观硬约束

---

## 一、境界体系（硬约束）

```
淬体期（新手）：搬石→碎砖裂石→无法御气
炼气期（外门）：御气→灵觉初开
筑基期（内门）：御剑飞行→神识外放
金丹期（长老）：一击毁城
元婴期（宗主）：瞬移+近乎无限战力
渡劫期（传说）：大圆满
```

### 能力边界
| 境界 | 可用能力 | 禁用能力 |
|------|---------|---------|
| 淬体 | 肉身力量、基础剑诀 | 御剑飞行、神识、灵气外放 |
| 炼气 | 灵气操控、灵觉 | 凌空飞行、神识扫描 |
| 筑基+ | 御剑、神识 | 瞬移（金丹+） |

## 二、体质体系（硬约束）

### 体质分类

```
传说级（≤1%）：天命体、剑骨
稀有级（5%）：天炎体、玄冰体、煞体
普通级（60%）：金/水/木/土灵体、凡体
特殊级（5%）：无相体、废体
```

### 体质效果表

| 体质 | 战力修正 | 特殊能力 | 适配功法 |
|------|---------|---------|---------|
| **天命体** | +30% | 天命剑专属共鸣 | 任意（但天命剑认主） |
| **剑骨** | +20% | 剑道感悟×2 | 仅限剑道类 |
| **煞体** | +25%（魔功）/-10%（正道） | 魔功抗性强 | 血煞门魔功 |
| **天炎体** | +15%（火）/-20%（冰） | 火焰伤害↑ | 火系功法 |
| **玄冰体** | +15%（冰）/-20%（火） | 寒毒入体 | 冰系功法 |
| **无相体** | 0% | 免疫属性克制 | 修炼速度-30% |
| **凡体** | 0% | 无 | 任意 |
| **废体** | -20% | 隐藏觉醒线 | 前期劣势 |

### 核心规则
- ❌ 非天命体不可感知天命剑觉醒
- ❌ 非剑骨修炼剑法无加成
- ❌ 煞体修炼正道功法效果减半

## 二、门派规范（硬约束）

| 门派 | 核心设定 | 禁用物品/行为 |
|------|---------|--------------|

## 三、神器规范（硬约束）

### 天命剑设定
- **神器自秽**：伪装成锈铁剑，外人无法识别
- **主角唯一感知**：只有淬体三重萧辰能感知其异动
- **觉醒条件**：生死危机/血脉共鸣
- **代价**：消耗寿命

### 感应规则
- ❌ 淬体/炼气期弟子不可感应神器觉醒
- ❌ 全场景不可"同时感知"
- ✅ 只有主角能隐约感知（心跳漏拍/肌肉反应）

## 四、时间线规范（硬约束）

### 章节时间流
```
清晨（天没亮）→ 日出三刻 → 中午 → 傍晚 → 夜晚
```

### 关键节点
- **大比开始**：日出三刻后集合
- **钟声响起**：三长两短
- **尚未发生**：用"即将开始"而非"还没开始"（避免矛盾）

## 五、角色行为规范（软约束）

### 境界→行为匹配
| 境界 | 行为特征 | 示例 |
|------|---------|------|
| 淬体三重 | 坚韧、沉默、观察 | "萧辰充耳不闻，只是继续挥剑" |
| 炼气初期 | 高傲、距离感 | 不主动接触淬体期弟子 |
| 筑基期 | 威严、俯视 | 不直接过问外门事务 |

### 反派行为逻辑
- ❌ 不直接说破秘密（暗示即可）
- ❌ 不正派语气说话（威胁/讽刺/冷漠）
- ✅ 用信息差制造压迫感

## 六、逻辑审查规则（logic-review.py）

### P0 级（阻断）
1. 时代词汇：办公室/手机/电脑等现代词
2. 境界能力越界：淬体期出现御剑飞行
3. 神器感应越界：非主角感知神器觉醒

### P1 级（警告）
4. 时间线矛盾：开始集合 vs 即将开始
5. 位置行为矛盾：最末尾 vs 最早
6. 门派设定冲突：天剑宗出现阔刀

### P2 级（建议）
7. 因果链漏洞：秘密泄露路径不明确
8. 信息不对称：角色获取信息无合理路径
