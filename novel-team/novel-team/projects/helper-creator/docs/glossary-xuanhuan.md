# 玄幻术语对照表（写作前必查）

> v2.0 | 2026-09-30 | 左栏词在正文中一律禁用，改用右栏

## 一、时间
| 禁用 | 改用 |
|------|------|
| 秒 | 一息 |
| 分钟 | 一盏茶 |
| 小时 | 一时辰 |
| 24 小时 | 一昼夜 |
| 倒计时（数字） | 刻漏将尽 / 灵漏只剩三刻 / 沙晷 |
| 第 X 天 | 入夜 / 不多时 / 又过了一盏茶（事件驱动，不报数） |

## 二、科技/现代单位
| 禁用 | 改用 |
|------|------|
| ℃ / 摄氏度 | 火候三分之差 / 温火 / 文火 / 武火 |
| 精度 ±N | 火候不差半分 / 分寸之间 |
| 温度控制 | 校火 / 候火 / 定焰 |
| 监控 | 守炉 / 候火 |
| 数据 / 信息 / 系统 | 阵纹 / 灵讯 / 天机 |
| 数据库 / 面板 / 界面 | 灵晷 / 铭刻 / 识海（慎用，忌系统流壳） |

## 三、游戏化外壳（金手指词汇玄幻化）
| 禁用 | 改用 |
|------|------|
| 任务发布 | 匣中纹路亮起，显出一道天机 |
| 奖励：灵力+3 | 匣身刻纹增二道 |
| 解锁新模块 | 又开一诀 |
| 模块 | 诀 |
| 系统提示 | 匣声 / 铭音 |
| 提示音 | 铭音 |

## 四、机构与职场词
| 禁用 | 改用 |
|------|------|
| 阁老 | 长老（阁老为明清官称，不入宗门） |
| 职位 / 岗位 | 司职 |
| 项目 / 计划 | 差事 |
| 团队 | 同门 / 弟子 |
| 失败率超过七成 | 十炉毙七 / 十炉成三 |

## 五、现代物件
| 禁用 | 改用 |
|------|------|
| 记录板 | 竹简 / 骨册 |
| 工具袋 | 储物袋 / 布袋 |
| 说明书 | 无（金手指不给说明，只给感觉） |

## 六、写作自检口诀
1. 写完先搜：`秒 分钟 小时 温度 精度 ℃ 监控 任务 奖励 模块 系统 数据` —— 命中即改
2. 搜 `---` —— 正文里出现即视为硬切，必加过渡桥段
3. 搜时间报数 —— 一章不超过 1 处"第X"
