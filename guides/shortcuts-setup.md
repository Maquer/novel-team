# Apple Shortcuts 自动化配置指南

> 用途：为 countdown-scheduler 提供硬后台兜底，确保 App 被杀后也能按时补跑积压任务。

---

## 一、创建定时自动化（推荐）

### 步骤

1. **打开「快捷指令」App**
   - 在手机桌面找到「快捷指令」图标（蓝色箭头）
   - 如果没有，从 App Store 搜索安装

2. **进入自动化页面**
   - 点击底部导航栏「自动化」
   - 点击右上角「+」（新建）

3. **选择触发条件**
   - 点击「添加触发条件」
   - 选择「定时」
   - 设置：
     - 「每天」
     - 时间：`08:00`（或你希望的时间）
   - 关闭「在触发前询问」（重要！否则需手动确认）
   - 点击右上角「下一步」

4. **添加操作**
   - 点击「添加操作」
   - 搜索「运行 Shell 脚本」
   - 点击进入并填写：
     ```
     python3 /var/minis/shared/countdown-scheduler.py check --catchup
     ```
   - 点击右上角「完成」

5. **关闭询问确认**
   - 系统会提示「是否允许快捷指令执行此操作？」
   - 确保开关是**绿色**（允许执行）

6. **完成**
   - 顶部会显示「每天 08:00 触发」
   - 自动化已生效

## 二、验证配置

### 测试一次

```bash
# 手动运行一次，确认命令有效
python3 /var/minis/shared/countdown-scheduler.py check --catchup
```

### 检查自动化是否生效

1. 打开「快捷指令」→「自动化」
2. 找到刚创建的自动化
3. 确认状态开关是绿色
4. 点击查看详情，确认「下次运行」时间正确

## 四、注意事项

| 事项 | 说明 |
|------|------|
| **首次使用** | 系统可能要求授权「未经验证的开发者」，按提示确认 |
| **网络需求** | Shell 脚本在 iSH 内运行，需要网络连接才能访问 Obsidian/外部服务 |
| **电量影响** | 定时自动化会唤醒设备，建议在充电时配置 |
| **系统更新** | iOS 大版本更新后可能需要重新授权 |
| **修改内容** | 如需更改脚本路径，编辑自动化 → 修改「运行 Shell 脚本」操作 |

## 五、故障排查

### 问题：自动化不触发
- 检查「快捷指令」→「自动化」里开关是否开启
- 检查手机是否处于低电量模式（会暂停定时任务）
- 重启手机后重新测试

### 问题：Shell 脚本执行失败
```bash
# 手动测试看错误信息
python3 /var/minis/shared/countdown-scheduler.py check --catchup
```
- 确认路径 `/var/minis/shared/countdown-scheduler.py` 存在
- 确认脚本有执行权限：`chmod +x /var/minis/shared/countdown-scheduler.py`

### 问题：需要每次手动确认
- 编辑自动化 → 找到「运行前询问」开关 → 关闭

## 六、高级：用 minis-scheduled 替代

如果不想用 Shortcuts，可以用内置调度器：

```bash
# 创建每天早上 8 点的提醒（仅 App 存活时有效）
minis-scheduled create --prompt "检查倒计时调度器补跑积压" --time 08:00 --repeat daily
```

但这是 best-effort，不如 Shortcuts 可靠。
